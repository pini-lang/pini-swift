# Pini 诊断错误码登记表（T1，2026-08-24 批次 A）

> **⚠️ 权威性（已降级）**：本文件为诊断错误码的**人类可读派生视图**，**迟维护、低权威**。
> 错误码 → 消息/建议模板的**唯一权威映射在 TOML 资源**：`Sources/PiniCore/Resources/Diagnostics.{en,zh}.toml`（见 spec「诊断错误码权威映射」）。
> **新增错误码只须登记 TOML**（append-only）；本表可落后于 TOML，不一致时以 TOML 为准，不视为规范违规。
> 本表仅作快速查阅，随批次顺手同步，不纳入一致性门禁。

> **定位**：错误码体系登记（`DiagnosticProviding` 协议元数据，源码见 `Sources/PiniCore/Common/Diagnostic.swift`）。
> 渲染由 `ErrorFormatter.formatDiagnostic` 消费（`Error: <类型> [<code>]`）。域段：E0 通用 / E1 词法 / E2 语法 / E3 语义 / E4 类型 / E5 运行时 / E6 IR 生成。
> 约定：**append-only**——已分配的码不删除、不复用；新码追加段内编号（以 TOML 为登记入口，见上）。
