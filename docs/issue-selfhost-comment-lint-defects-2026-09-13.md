# Issue：selfhost 侧 comment-lint 仍带宿主已修的三个缺陷

- 状态：**Open（2026-09-13 立案；不修 —— selfhost 冻结期内，见「为何暂不修」）**
- 层级：**宿主级** —— 工具链副本一致性；改的是 selfhost 仓内的门禁脚本，不涉语言契约
  （层级判据见 `ADR-024 D6`；目录约定见 `docs/README.md`）
- 发现来源：宿主侧门禁修复后的**多端复核**（修复提交 `1833f7a`）
- 关联：`hooks/comment-lint.sh`（宿主侧，**已修**）；
  `examples/selfhost/hooks/comment-lint.sh`（本单对象，**同一脚本的英文版**）；
  `ADR-024 D2`（嵌套独立仓）；`ADR-031 约束 6`（「PATH 探针」族缺陷的规范出处）

## 现象

宿主侧门禁脚本在 2026-09-12 修掉三处缺陷后，**selfhost 那份副本三处全在**：

| # | selfhost 位置 | 形态 | 后果 |
|---|---|---|---|
| 1 | 第 50 行 | `command -v rg >/dev/null 2>&1 && has_rg=1` | 只查 `PATH` ⇒ rg 装着也可能静默回退最慢后端（单趟 79 秒 vs 0 秒 × 7 趟） |
| 2 | 第 99 行 | `grep -vxF -f <(printf …) \|\| true` | 进程替换被禁时该 grep 失败，被 `\|\| true` 吞掉 ⇒ 打印「✅ all ADR IDs redeemable」而**一条都没查** |
| 3 | 第 96–97 行 | 登记表读不到 ⇒ `⚠️ … skipping`（**rc=0**） | 判据**入口**失效被当成一次通过 |

宿主侧对应修复（`1833f7a`）：① 探测加绝对路径候选；② L6 改纯 bash 比对
（无外部命令、无临时文件、无进程替换）；③ 加三道守卫 —— 登记表读不到 / 扫描零命中 /
引用不可兑付。

## 与宿主侧的额外差异（解冻时需一并裁决）

selfhost 的 L6 指向**跨树相对路径**（自该仓根**上溯两级**回到宿主仓的
`docs/spec/adr/adr-index.md`），其注释写明设计意图是「**standalone 时优雅跳过**」
（该仓为嵌套独立仓，单独检出时看不见宿主登记表）。

⇒ 直接照搬宿主侧的「登记表读不到 ⇒ `fail=1`」**会破坏 standalone 可用性**。
故第 3 条须单独裁决，候选：

- **选项 A**：standalone 时输出**显式** `[L6] skipped (standalone)`，保持 rc=0。
  现状 `⚠️ … skipping` 的问题不在「跳过」，而在**无法区分「standalone」与「路径写错」**。
- **选项 B**：加哨兵探测（宿主仓是否存在），区分「standalone」与「配置漂移」，后者 `fail=1`。
- **选项 C**：维持现状，仅同步第 1、2 条。

## 为何暂不修

- selfhost 仓处于**冻结期**（用户裁决：HIR 重构完成前不动 selfhost，改动风险过高）。
- 该仓**无 remote、无 CI**（已实测 `git remote -v` 为空、无 `.github/workflows`）
  ⇒ 缺陷**不会自动分发**到其他端，当前影响限于本地手工调用。
- 一旦 selfhost 解冻或独立分发，本单即为同步清单。

## 解冻时的修复姿势

逐条对齐宿主侧 `hooks/comment-lint.sh` 的三处改动；第 3 条按上节裁决结果落地。
验证复用宿主侧同一套探针：**三道守卫各自独立变红**（探针须各自 `git init` 成为独立仓根，
否则扫描范围会上溯串味）+ **干净树对照组通过**（证明不是「一律变红」）。
两后端（rg / grep）都要跑一遍 —— 该仓无 rg，实际只走 grep 后端。
