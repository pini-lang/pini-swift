# 格式化对账读数

本件是交付证据，不是筹划载体：工具面的分组、次序与判据写在 `docs/plans/2026-11-12-self-hosting-plan.md`
的 **工具面** 一节，这里只存打印器交付时的实测读数与探针。

注意 读数易腐。它们绑定当次的机器、工具链与源码规模；实现一变即失去可比性，引用时只可作
「当时差多少」的依据，不可当作验收判据。

## 环境

| 项 | 值 |
|---|---|
| 机器 | macOS 27.2.1，arm64 |
| 宿主编译器 | `.build/release/pini`，Apple Swift 6.4.2（swiftlang-6.4.2.1.9） |
| 自举编译器 | `bootstrap/.build/release/bin/pini-bootstrap`，同源首代产物 |
| LLVM 工具 | Homebrew clang 23.1.5 |
| 被测源码 | `bootstrap/packages` 与 `bootstrap/stdlib`，233 个 `.pini` 文件 |

## 三条判据

| 判据 | 命令 | 读数 |
|---|---|---|
| 整树零改动 | `pini-bootstrap fmt --check bootstrap/packages bootstrap/stdlib` | 零输出，退出 0；233 文件逐个 `fmt` 后与源逐字节相同 |
| 幂等 | 每文件 `fmt` 两次，比两次输出 | 309 个文件（源码树加示例）全部相同，零例外 |
| 与宿主同形 | 65 个示例两侧各 `fmt` 一次，`diff` 两份输出 | 65 / 65 逐字节相同，零差异 |

## 注释锚回

三条落点按位置判定，不读原文空白：行尾注挂同源行末（隔一空格）、块内注挂下一处锚点之前、
块尾注挂上一处锚点之后。`examples/comments.pini` 与宿主逐字节相同；块首注释上方的空行按块内
规则丢弃，两侧一致。

## 交付过程中被读数逼出来的缺陷

| 现象 | 根因 | 处置 |
|---|---|---|
| 类型体成员多缩一层 | 类型体是顶格块，成员与块头同列 | 成员体不再进缩进栈 |
| `-> (T, )` 多一个空格 | 返回表逐项追加 `, ` | 逐项以 `, ` 相接、末项补 `,` |
| 特征签名凭空写出 `\|func` | 解析时丢掉 `\|func` 标记，打印按「其余都没写」推测 | 声明节点记 `isFunc`，按源还原 |
| `-> ((T, U,),)` 掉一层括号 | 折叠后与 `-> (T, U,)` 树同形 | 声明节点记 `returnNested` |
| 解构声明打印越界 | 变量行取子节点未判长度、打印目标时传了空源 | 补守卫并按真实源位置取行号 |
| 标签实参打印越界 | 标签实参节点只有一个子（值），代码取第二个 | 改取首子 |
| 字符串里的 `\r\n` 印成控制字节 | 字符串按字素簇切分，CRLF 是一个簇 | 还原与转义都按字节走 |
| 多行容器元素缩进差一级 | 元素列按固定 4 推，源里是作者缩进 | 观察源缩进差并量化到 2 / 4 / 8 |
| 前缀 `!` 印成后缀 `!` | 前后缀同用一枚记号，判定只看记号不看位置 | 按节点与操作数的起点判前后缀 |
| 多行调用收尾挤在末行 | 未按宿主规则把 `)` 另起一行 | 体里有换行时收尾回父列 |
| 枚举项丢点前缀、模式里的 `none` 写成 `Optional.none` | 表达式与模式共用一条打印路径 | 按源首字节补点；模式分支单列 `none` |
| 泛型调用丢标签实参 | 泛型实参逐个按表达式打印，标签实参节点只有一个子，被印成空串 | 改走实参表打印 |

## 已知差异

| 差异 | 表现 | 登记去处 |
|---|---|---|
| 路径前缀 | `fmt --check` 列出的路径宿主去掉 `./`，自举原样回显 | 对照夹具 `fmt-check-dirty`（`同同异`） |
| 错误文案通道 | 多路径缺开关两侧都拒；宿主把说明写标准错误，自举写标准输出 | 对照夹具 `fmt-multi-path`（`同同异`） |
