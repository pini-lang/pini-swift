# 异步语义面

## 目标与边界

补两条检查：`await` 与 `wait` 只能用在与函数体类别相符的位置（`E6-009`）；`await` 不能落在没有可恢复
续跑点的位置（`E6-010`）。

边界：本件只做**检查**，不做异步运行时。真让出、任务树调度归 **并发语义检查**；
`await` 在解释通道的合规降级也在那件。本件的产出是「写错了在检查期就红」，而不是「跑起来才发现」。

## 批次

### 一、体类别进语义层

函数声明把「异步 / 同步」带进语义面的函数签名，闭包字面量同样带。类别是签名的一部分，
调用点不需要知道，只在体内判。

判据：同一函数分别写成 `=>` 与 `->`，语义面能读出类别（取数：`dump` 或接口面）。

### 二、`E6-009` 位置匹配

沿表达式上下文向上找最近的函数体，比类别：`await` 要求在异步体、`wait` 要求在同步体。
跨闭包时以闭包自身的类别为准，不继承外层。

判据：四种组合各一例：异步体 `await` 通过、异步体 `wait` 报 `E6-009`、同步体 `wait` 通过、
同步体 `await` 报 `E6-009`。

### 三、`E6-010` 可恢复点

`await` 要能回到精确续跑点。落在不能续跑的位置（如条件表达式的求值中、`defer` 体内）时报 `E6-010`。
判据按参考件的可恢复点定义，不由实现反推。

判据：`E6-010` 发出；位置相邻但可续跑的写法不报；差异表删该行。

## 风险与裁定

| 风险 | 处置 |
|---|---|
| 可恢复点的定义写不细，检查变成猜 | 先补参考件条款再补检查；条款没写的形态不判红，只登记 |
| 与并发件的 `await` 降级互相等 | 两件共用「体类别」这一份数据；检查先落地，降级后做，不互为前置 |
| 闭包跨层继承类别导致误报 | 闭包自身带类别，不继承外层；跨层用法按闭包类别判 |
| 检查过严拒掉尾调用位置的 `await` | 尾位置可续跑，按可续跑放行；判据是「能否回到精确续跑点」，不是语法位置枚举 |
