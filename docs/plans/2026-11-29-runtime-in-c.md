# 运行时 C 化

## 目标与边界

把运行时段 `PiniRuntime` 从 Swift 换成 C：同一份 135 条符号面、同一套语义，换实现语言。
完成后产物不再依赖 Swift 运行时，跨平台只剩系统库与 LLVM。

边界：不改 ABI——符号名、参数、返回值、语义约束一条不变（`docs/spec/runtime-abi.md` 是判据）。
不改语言面语义。`asyncDeinit` 的真实调度仍不在线内。本件不碰编译器，只碰运行时段。

## 缺口与读数

| 项 | 现状 | 取数入口 |
|---|---|---|
| 实现 | `Sources/PiniRuntime/PiniRuntime.swift` 共 3924 行 Swift | `wc -l` |
| 符号面 | 135 条，分 11 族（句柄、名义箱、错误字、陷阱、路径基准、并发、字符串句柄、建目录、进程、行输入、工具链位置） | `docs/spec/runtime-abi.md` §2 |
| 平台分支 | 存在 `#if canImport(Darwin)` 覆盖的 Linux 分支 | `Sources/PiniRuntime/` |
| 零调用点 | 与内建互斥的登记表由 `tools/builtin-inventory-check.py` 校验 | 同名脚本 |
| 依赖 | 产物链接 `libPiniRuntime`；自举产物与宿主产物共用 | `tools/runtime-lib.sh` |

## 批次

### 一、骨架与符号外壳

建 C 目标，先落 135 条符号的空实现（返回陷阱或零值），链接打通、清单核对一致。这一步的价值是
把「符号面」与「实现」分开：外壳全绿之后，逐族替换不再动链接面。

判据：`tools/runtime-abi-check.py` 通过；符号数 135；空实现下全量测试全红（说明外壳真的被调用）。

### 二、字符串与容器族

字符串句柄、容器（数组 / 字典 / 集合）、比较与哈希。这一族调用最密，先做能把最大的一片行为带过来。

判据：`examples/stdlib-*.pini`、`collections.pini`、`cow.pini` 三通道一致。

### 三、名义箱与计数族

对象箱、struct 箱、引用计数、弱引用与无主引用的存活判定。这一族与 **引用计数进解释器** 共用语义，
但实现各自独立。

判据：`examples/object.pini`、`deinit.pini`、`lazyref.pini` 输出与 golden 一致；泄漏读数不高于换实现前。

### 四、并发族

任务、Future、取消与汇合。这一族依赖线程与同步原语，C 侧要自带，不借宿主运行时。

判据：`examples/concurrency*.pini` 在发射通道全部通过；同一夹具两次运行行序按多重集相同。

### 五、IO、路径与进程族

文件读写、路径基准、行输入、目录创建、进程与工具链位置。这一族与宿主环境耦合最深。

判据：`tests/PiniTests/AppendFileTests` 等价用例在 C 侧通过；`resolveIOPath` 的 `./` 豁免保持。

## 风险与裁定

| 风险 | 处置 |
|---|---|
| C 实现与 Swift 版行为漂移 | 每族换完先跑「两版并存对照」：同一夹具两版各跑一次，输出逐字节比，一致才删旧实现 |
| 平台分支在迁移中被固化 | 目标就是消掉 `#if canImport(Darwin)`；迁移完还有分支即判未完成 |
| 内存安全（C 无 ARC） | 每族配泄漏与越界探针；`vmmap` 读数与 ASan 至少一项进判据 |
| 与提速、并发、计数三件交叉 | 本件排期放在那三件之后；符号面先冻结，避免边改边迁 |
| 迁移期间两版符号同名 | 用构建开关切，不同时进产物；开关只在迁移期存在，收尾时删除 |
