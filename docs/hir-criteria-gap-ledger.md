## 5. 纪律条款（供各格开工自检；无代码可改，只能改读法）

1. **覆盖面的判据是「通道对」，不是「套件名」**（CG-04）。`HIRDifferentialTests` 这个名字会让人
   以为「HIR 已被差分覆盖」，而它比的是 `ast ⇄ llvm 管线`、**不经过 HIR 解释器**。
   ⇒ 问「这个面覆盖了吗」时，必须答**覆盖了哪一对通道**；`llvm⇄hir` 与 `hir⇄ast`
   由**另外两个器械**承担。
2. **对照必须与变异面正交**（CG-09/10 的同族教训，源自 `slice` 反例）：`slice` 看似是
   纯容器对照，实则**同一内建方法两通道走不同路线**（AST 走 Pini 标准库、HIR 走原生 `.sliceCall`），
   于是它成了「第二个可观测者」—— 红不是因为对照失效，而是因为**对照恰好在变异面上**。
   ⇒ 对照要选**不触碰**被变异族（match / optional / try / 字面量 / 内建）的纯算术 parity 用例。
3. **「跑过某个子集」不能升级为「知道该面的覆盖面」**（CG-04 的过程留档）：该结论起初据子集
   误判为「XCTest 面对 HIR 缺口全失明」，跑全量当场推翻。
