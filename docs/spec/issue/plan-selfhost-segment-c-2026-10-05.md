## 1. 段 C 的终局定义

段 C = **贯通与收口**（后端件 §3.3）。判据**四条同批成立**才算销账，⛔ **不许互相抵扣**：

| 判据 | 内容 |
|---|---|
| **C①-a 覆盖自洽** | 源码声明的函数面**全部**落在产物里（右端 = **源码自身**，⛔ 不是宿主） |
| **C①-b 产物可用** | 产物能被下游消化，并沿**产物可用阶梯**走到**梯 4** |
| **C② 行为等价** | 整包产物的**行为**与右端一致 |
| **C③ 自举自编** | 自举发射器产的二进制**能编译自举源码自身并能跑** |

⚠️ **C② 今天只有「一半」有判据**：阶梯器械比的是「自产产物编出的东西 ↔ **对照方产物**编出的东西」；
「与**解释器**一致」那一半要**装配通道** ⇒ 另一条账（器械件头自陈）。
⭐ **建议拆**：**C②-a（对对照产物）** / **C②-b（对解释器）** —— 理由与 C① 拆两半**同形**：
不拆则「哪一半没达」在读数上不可见，而两半的**前置完全不同**（a 只要梯 1–3，b 还要装配通道）。
⇒ 在册待裁项之一。
