## 5. 风险与约束

1. **第 3 层断言层**（器械）：锚点绑定规范「值展示语义」条；该条递交时须同批改
   `Tests/PiniTests/SpecAssertionTests/PROVENANCE.md` 并重跑，否则该层静默降级为第 1 层。
2. **语言面锚点 70+ 处**：分布在约 60 个文件（ADR / 工单 / 计划 / README / HIR 契约）。
   改指必须**在该条递交的同批**进行，不早于递交（避免指向尚未接收的位置）。
3. **形式文法的注释溯源**：删除规范附录前，须把产生式上的裁决溯源（反引号转义 / 宽松词法 /
   `except` 移除等）逐条补入语言参考，否则丢的是「为什么这么定」。
4. **工程面锚点约 100+ 处不受影响**（变更治理 / 证据协议 / 缺口台账 / 测试与注释规范留在规范）。
5. **引用纪律**：跨文件指向一律用主题词；豁免仅「语言细则索引」一节、机器元数据字段与
   历史归档快照。
