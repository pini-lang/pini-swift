# selfhost 差距台账（P2 轨的**销账单位**）

> **本件是什么**：自举侧与**权威面**之间「特性差距」的**受管载体**。每一行 = 一项差距 +
> **契约条目号** + **宿主参照位** + 自举现状 + 销账条件。P2 轨每回填一格，**以本表销行**。
>
> **出身**：本表由二期件 `plan-selfhost-evolution-2026-09-30.md` §1.2 的**立项差距表升格**而来
> （P2-0 判据③）。⚠️ 那张表是**立项快照**；升格时**未逐行重测**（见 §2）。
>
> **权威关系**：右端一律取**权威载体**（契约 / 语言参考 / 规范件），⛔ **不以宿主实现为定义处**
> （判据定式 1，见 `plan-selfhost-criteria-2026-09-30.md` §3.3）。「宿主参照位」栏是**指认位置**，
> 不是判据右端。
>
> **维护规则**：① 一行只在一处（本表）；② 销行须在**当批**完成（批内回填）；③ 新增行须带
> 契约条目号或「无对应节点」的判定；④ ⚠️ 本表**不记行数/耗时**（会漂 ⇒ 那些在自举仓
> `docs/baseline-p2-0.md` 与 `docs/boundaries.md`）。

## 2c. 一条非特性类缺陷 —— **未终止插值 ⇒ 解析器不终止**（2026-10-01 立 → 同日当场修）

- **现象（两侧实测）**：源里写 `let s = "a\(b"`（插值的 `)` 缺失）时 ——
  - **宿主**：`Error: Lexer Error [E1-002] ... unterminated string literal`，**rc=1**；
  - **自举（修前）**：`pini run . parser-decl <该文件>` **20 秒未返回、被强杀** ⇒ **不终止**。
- **机制**（`examples/selfhost/src/parser/expr.pini` 的 `interpSegmentsFrom`）：`exprEnd` 初值为 0，
  平衡扫描找不到 depth 0 时不赋值 ⇒ `j = exprEnd + 1 = 1`；而递归调用
  `interpSegmentsFrom(s, j, …)` 的 `i` 也可能是 1 ⇒ **同一实参自递归**（每次都不前进）。
  ⚠️ 词法层**不是**成因：它按 §A.1.1 的**宽松词法**（已裁边界）在这个输入上照样发
  `interpolatedString` ⇒ 解析层接到的是一个「引号闭了、插值没闭」的串，必须自己能收场。
- ⚠️ **归属**：**先于** 2026-10-01 的插值批存在。依据 = 该批差异
  （`git show 241ae7f -- src/parser/expr.pini`）不触那三处；⚠️ **未在改动前的树上实测**。

### ✅ 处置一（已交付）：**不终止**这一半 —— 已修 + 判据⑫ + 两条变异反证

- **修法**：平衡扫描引入 `closed` 标志；找不到收尾时**提前返回**，把「从 `\(` 起的**原文**」

  ⭐ 取「**保留原文、不解码**」：解码是一种**解释**，对已判畸形的输入做解释会丢原文。
