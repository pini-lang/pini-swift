# selfhost 差距台账（P2 轨的**销账单位**）

> **本件是什么**：自举侧与**权威面**之间「特性差距」的**受管载体**。每一行 = 一项差距 +
> **契约条目号** + **宿主参照位** + 自举现状 + 销账条件。P2 轨每回填一格，**以本表销行**。
>
> **出身**：本表由二期件 `plan-selfhost-evolution-2026-09-30.md` §1.2 的**立项差距表升格**而来
> （P2-0 判据③）。⚠️ 那张表是**立项快照**；升格时**未逐行重测**（见 §2）。
>
> **权威关系**：右端一律取**权威载体**（契约 / 语言参考 / 规范件），⛔ **不以宿主实现为定义处**
> （判据定式 1，见 `plan-selfhost-criteria-2026-09-30.md` §3.3）。「宿主参照位」栏是**指认位置**，
> 不是判据右端。
>
> **维护规则**：① 一行只在一处（本表）；② 销行须在**当批**完成（批内回填）；③ 新增行须带
> 契约条目号或「无对应节点」的判定；④ ⚠️ 本表**不记行数/耗时**（会漂 ⇒ 那些在自举仓
> `docs/baseline-p2-0.md` 与 `docs/boundaries.md`）。

## 2b. ✅ 一条**非特性类**限制 —— **已了**（2026-10-01 登记 · 同日处置 · 本节保留作记录）

- **源文件尺寸**（原文）：语言的 `readFile` 有**固定字节上限**，越过者被**静默截断**（无诊断 ·
  退出码 0）⇒ 自举前端读到**半个文件**，于是把一份**合法源**报成语法错。
  ⛔ 它**不是特性差距**（不是「权威面有、自举没有」），故**不进 §1 的表**；
  但它是本轨**实际卡住判据**的一条 —— 自举侧「解析不过的文件数」那一项的真因就是它
  （此前登记为「解析器形态缺口」，是**误归因**）。
- ⭐ **结果**：上限本身在**宿主侧**被删除（`auth-70`）⇒ 本约束**消失**；当时设的机械判据
  （自举仓的尺寸判据）**已退役**，保护改由**宿主侧**读入判据承担（超旧上限的文件两腿都须整份读入）。
  ⚠️ 按该约束切分出的文件**保留**（⛔ 不回切：切分本身是好的结构）。
- **保留本节的理由**：它记的是一次**误归因的翻案**与一次「**症状侧判据 → 成因侧判据**」的搬迁 ——
  两件都比那条限制本身值钱。

## 2c. 一条非特性类缺陷 —— **未终止插值 ⇒ 解析器不终止**（2026-10-01 立 → 同日当场修）

- **现象（两侧实测）**：源里写 `let s = "a\(b"`（插值的 `)` 缺失）时 ——
  - **宿主**：`Error: Lexer Error [E1-002] ... unterminated string literal`，**rc=1**；
  - **自举（修前）**：`pini run . parser-decl <该文件>` **20 秒未返回、被强杀** ⇒ **不终止**。
- **机制**（`examples/selfhost/src/parser/expr.pini` 的 `interpSegmentsFrom`）：`exprEnd` 初值为 0，
  平衡扫描找不到 depth 0 时不赋值 ⇒ `j = exprEnd + 1 = 1`；而递归调用
  `interpSegmentsFrom(s, j, …)` 的 `i` 也可能是 1 ⇒ **同一实参自递归**（每次都不前进）。
  ⚠️ 词法层**不是**成因：它按 §A.1.1 的**宽松词法**（已裁边界）在这个输入上照样发
  `interpolatedString` ⇒ 解析层接到的是一个「引号闭了、插值没闭」的串，必须自己能收场。
- ⚠️ **归属**：**先于** 2026-10-01 的插值批存在。依据 = 该批差异
  （`git show 241ae7f -- src/parser/expr.pini`）不触那三处；⚠️ **未在改动前的树上实测**。

### ✅ 处置一（已交付）：**不终止**这一半 —— 已修 + 判据⑫ + 两条变异反证

- **修法**：平衡扫描引入 `closed` 标志；找不到收尾时**提前返回**，把「从 `\(` 起的**原文**」
  并入字面缓冲、只产**一条字面段**（⇒ 该路径上根本不递归）。
  ⭐ 取「**保留原文、不解码**」：解码是一种**解释**，对已判畸形的输入做解释会丢原文。
- **判据⑫**（自举仓 `tools/check-parser.sh`）：⭐ 形状与本轨其余判据**不同且必须不同** ——
  其余判「读数对不对」，本条判「**跑不跑得完**」⇒ 带**超时**包装（本机无 coreutils `timeout`，
  用 `perl -e 'alarm shift; exec @ARGV'`；退码 **142** 作判据，⛔ 不用「跑得久」判）。
  ⚠️ 超时包装**只许挂在这一条**上（给全器械加公共超时会误伤分钟量级的项）。
- **变异反证两条**（都**只打⑫** · 其余 15 行全绿 · 还原后与备份逐字节一致）：
  回到旧行为 ⇒ 红在「不终止」；降级时丢内容 ⇒ 红在「形状」。
  ⚠️ 两处**如实登记**（⛔ 别读成「都验过了」）：⑫ 内部两条子断言在「不终止」时**耦合**

- ⭐ **对模块自检的影响**（**实测**，⛔ 不是假设）：
  - **判据面全达**：`U5 = 0`（本轨的判据）· `U4 = 0` · `U7 = 0`；**`U8` 未动**（231）。

### ⚠️ 处置二（**未了 · 属规范面待裁**）：「该报什么」这半边 —— 权威面**没有明文**

- ⛔ **不得**按宿主实现对答案（判据定式 1）。两侧行为**不同形**，而**宿主那一侧本身有缺陷**：
  - 宿主在同一输入上报的位置是 **15:1**，而该文件**只有 12 行**
    ⇒ **报错位置指向不存在的行**（它一路扫到 EOF 才判定未闭合）。
    ⇒ 拿它当右端，等于把一条**已知有缺陷**的读数当权威。⭐ 这正是本仓
    「**归因前先标定读数**」那条纪律的又一个实例（报错位置可能本身就是坏的）。
  - 规范面**自身的张力**：§A.1.1 的宽松词法条写「词法器对**任何输入不报错**」且
    「字符串未闭合在**行尾**隐式终止」，而宿主在这个输入上报了 `E1-002`；
    同时 `INTERP ::= '"' { … | '\(' INTERP_EXPR ')' } '"'` 的产生式里
    **没有**「插值未闭合」这一形态 ⇒ 它落在一个**产生式不覆盖、宽松条又说不报错**的缝里。
- ⇒ **结论**：自举当前的「终止 + 静默降级」⛔ **不违背规范明文**（明文没写），
  但也**不能据规范宣称它「对」**。**待裁项**：插值未闭合该报什么码（或该不该报）、
  以及宿主那个错位报错要不要单独立案。**裁前**自举维持现状（已终止，不会挂住任何人）。
- ⚠️ **一条口径差（本批最值钱的一条）**：我原按 `L0` D2 判「**不阻塞** ⇒ 不修」，
  用户裁定「当场修」。两条并不矛盾 —— D2 判的是**要不要阻塞推进**，
  ⛔ **不是「要不要修」**。⇒ **不阻塞 ≠ 不修**。
