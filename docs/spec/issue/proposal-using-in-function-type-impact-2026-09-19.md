# `using` 进入函数类型 —— 影响评估（ADR-001 的延伸，2026-09-19）

> **本件在 `§1.3` 五步里的位置**：第 ① 步（提议）**不另立** —— 提议内容已在 ADR-001 的框架内，
> 且由用户 2026-09-19 裁定并入 `P3`（原话：「我认为这是与 using 同一批的改动，应当归属到 ADR-001，
> 因此在本批改动」）。本件承担第 ② 步（影响评估），下游由 ADR-001 承担第 ③ 步（登记）。
> ⚠️ 按「实现不得先于登记」，本件与 ADR 补节**先于任何源码改动**落笔。

---

## 0. 一句话

`using` 的取用位要**进入函数类型**（作为「哪些参数位可取用」的下标集合），
这样**匿名函数赋给变量后调用**仍能省略实参；同时**用户写不出**该标注，
因此**函数值经字段/参数传递后失去该能力** —— 这是**有意采纳**的边界，不是缺陷。

**触发它的那件事**：`P3` 开工勘测发现，ADR-001 设想的「体内直接写类型名绕过 `using`」
这条通路**不存在**（详见 §2.1）；而「匿名函数支持省略式」（用户裁定）在实现上
**必须**让取用位进类型，否则「声明不可见」的调用点读不到它。

## 1. 事实基础（逐条实测，2026-09-19）

### 1.1 取用位今天**不在**函数类型里

| 面 | 定义处 | 有取用位吗 |
|---|---|---|
| AST | `Type.swift:44` `case function(params:returns:captured:location:)` | ❌ |
| HIR | `HIRNode.swift:80` `case function(params:[HIRType], returnType:)` | ❌ |

⇒ 间接调用**在原理上无法**知道哪个位置需要插入取用点。

### 1.2 间接调用有两条路径，处境不同（`HIRLowerer.swift`）

- **经变量**（`3617`）：`case .function(let paramTypes, let functionReturn) = signature`
  —— 只解出类型序列，**取用位丢失**；`3620` 的 arity 检查因此按「实参个数 = 形参个数」判。
- **内联字面量**（`3640`）：`case .funcLiteral(let literalDecl, …)` —— `literalDecl.params` **在手**，
  取用位**可读**（今天只是没读）。

### 1.3 「声明不可见」时今天的报法**三种不一致**

| 形态 | `check` | `run` |
|---|---|---|
| 作实参传进另一函数，体内 `f()` | `E4-005` 参数数量不匹配 | 同 |
| 赋给局部变量 `var f = 取名` 后 `f()` | **通过** | **`E6-004`**「indirect call expects 1 arguments, got 0」 |
| 从对象字段取出后调用 | `E4-005` | 同 |

⇒ 第二行是「`check` 过了、`run` 拒」的**中间态**，属本仓反复清理的那一类。
⇒ 这条不一致**由本件一并消除**（消除机制见 §5.4）。

### 1.4 类型标注位的 `using` **今天已被拒**（因此用户要的那条规则零代码）

| 位置 | 实测判定码 |
|---|---|
| 字段的类型标注 `处理: (using 配置,) -> (String,)` | **`E2-008`** 无效的类型标注 |
| 局部变量的类型标注 `var g: (using I32,) -> (I32,)` | **`E2-008`** |

⇒ 用户裁定「**经过字段位置上的类型标注禁止 `using` 修饰**」**已经天然成立**
（`using` 是关键字，类型标注文法不接受它）。本件只需**登记 + 一条判据钉住**，
⚠️ 文案仍是通用句（「无效的类型标注」），**不带引导** ⇒ 见 §7 不覆盖面第 1 条。

### 1.5 函数类型里**已经有**取用位的参数类型

实测错误原文（`var g: (String,) -> (String,) = 取名`）：

```
type mismatch: function(params: [nominal(name: "配置", isObject: false)], returnType: String)
            is not function(params: [string], returnType: String)
```

⇒ 取用位的**类型**（`配置`）本来就在 `params` 里；**缺的只是一个下标集合**，
不是「一整套新的类型信息」。这是本件代价可接受的主要理由。

## 5. 代价与风险

### 5.1 两面等价判据不同源（本件最主要的技术风险）

- `TypeAnnotation: Equatable` 是**合成**的 ⇒ 加字段**自动进** `==`；
  但类型比对实际走**手写的** `isStructurallyEquivalent`（`Type.swift:53`）⇒ **默认不进**。
- `HIRType` 的 `==` 是**合成**的 ⇒ **自动进**。

⇒ 若不对齐，会出现「AST 面忽略、HIR 面比较」的**静默分裂**。
**处置**：两面对该位取**同一口径（忽略）**，并在两处各留一行注释说明「为什么忽略」，
判据里各钉一条（§8 第 4、5 条）。

### 5.2 为什么取「忽略」而不是「比较」

取「比较」的后果：用户**写不出**带取用位的标注（§1.4），因此**无法**为「带取用位的函数」
写任何显式标注 —— `var g: (配置) -> (String,) = 取名` 会报类型不匹配，
而用户**没有语法**去修它。⇒ 那是一个**无解的错误**。
取「忽略」：赋值合法，但 `g` 的**声明类型**无取用位 ⇒ `g()` 报 `E4-005`。

⇒ 两者都「失去能力」，但**忽略**不产生无解错误 ⇒ 取忽略。

### 5.3 「失去能力」的范围（有意采纳，非缺陷）

| 场景 | 取用位 | 省略式 |
|---|---|---|
| `var f = func (using 配: 配置,) …` → `f()` | **在**（推断产生） | ✅ 支持 |
| `(func (using 配: 配置,) …)()` 内联立即调用 | **在**（字面量在手） | ✅ 支持 |
| 显式标注裸类型后调用 | **不在**（用户写不出位） | ✗ `E4-005` |
| 作实参传入（形参标注是裸的） | **不在** | ✗ `E4-005` |
| 存进字段后取出 | **不在** | ✗ `E4-005` |

> **用户 2026-09-19 原话**：「考虑到此语言向来不在字段位置做细致修饰，`using` 应当采用
> **声明位置与调用位置配对**，经过字段位置上的类型标注禁止 `using` 修饰，
> 因此采纳『保存到字段上失去此能力』」

### 5.4 消除 §1.3 的三种不一致

取用位进类型后，**经变量调用**的检查器**知道**该值有位 ⇒ 按省略式判 arity ⇒
`var f = 取名; f()` **合法且真的物化**（不再是 `check` 过 / `run` 拒）。
而「位已丢失」的那些场景统一报 **`E4-005`**（与 p14/p16b 同码）⇒ 三种报法收敛成两种：
**能省略** 或 **`E4-005`**。

## 7. 不覆盖面（本件明确不做）

1. **`E2-008` 的文案不改** —— 用户在字段标注位写 `using` 会得到「无效的类型标注」，
   **不含引导**。改文案要动 `parseTypeAnnotation` 的通用句，属独立小批。
2. **不允许用户书写带取用位的类型标注**（`(using 配置) -> (String,)`）—— 有意。
3. **不追踪「函数值在运行时的取用布局」** —— 取用位是**编译期**事实，不进运行时表示，
   以维持 ADR-001「无运行时查找、无 vtable」。
4. **跨模块**（独立编译单元）仍无通路，同 `P2b`。

## 8. 判据计划（每条都须能红）

| # | 判据 | 观测口径 |
|---|---|---|
| 1 | 匿名函数赋给变量后省略实参 ⇒ 真的物化 | 值 + 副作用计数 |
| 2 | 内联立即调用省略实参 ⇒ 真的物化 | 值 |
| 3 | **对照**：显式标注裸类型后省略 ⇒ `E4-005`（能力确实失去） | 判定码 |
| 4 | 两面等价**同口径**：AST 面 `isStructurallyEquivalent` 忽略该位 | 直接断言 |
| 5 | HIR 面 `==` 与上一条同口径 | 直接断言 |
| 6 | 类型标注位写 `using` ⇒ `E2-008`（字段位与局部位各一） | 判定码 |
| 7 | **强制规则**：体内值位引用给定块类型名 ⇒ `E4-015`（不再漏到 `E6-004`） | 判定码 + 对照（object 类型名仍走旧路） |
| 8 | **参数位收窄**：trait 签名 / `\|test` / `main` / `\|foreign` 各拒 | 判定码 |
| 9 | **阴性**：合法面不受影响（具名调用省略、全显式、`main` 无参数、泛型给定块） | 全绿 |

**变异反证**：至少三级 —— ① 撤取用位（⇒ 判据 1/2 红）② 撤等价对齐（⇒ 4/5 红）
③ 撤收窄（⇒ 8 红）。**「不该红的不红」** = 判据 3/9 在三级变异下**保持绿**。
