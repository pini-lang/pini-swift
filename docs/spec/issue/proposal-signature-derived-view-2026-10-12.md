## 1. 动机

- **歧义归一**：切换前结构串抽取有**两份实现**（壳侧 awk + 语言侧移植），同一规则两处书写即漂移本体；
  宿主侧判据支撑功能规划已裁定「派生/抽取类功能的实现位置归宿主侧」（Swift 单一实现、无歧义、原生性能），
  本件是它在语言面与宿主实现上的落点。
- **性能**：语言侧逐字符循环在双层解释下每次调用约 0.1 秒量级（微基准实测），parser 语料行常跑面
  10–15 分；宿主序列化 + 比对后该行降至秒级。
- **宿主具备直读条件**：宿主持有完整 AST 与折叠后的常量（`parse` 入口与类型检查同序折叠），
  机械读出无歧义。

## 2. 方案（四件事，一个口径）

1. **语言规范立「结构串派生视图」条款**：钉死语料范围（main 函数体顶层语句、按书写序编号）、
   规范树渲染词表（节点名集合与字段名集合各 19 类、头部内联规则）、元素与结构串的抽取规则、
   输出形态（`SIG|<序号>|<结构串>`）、两侧一致性义务。语义唯一来源 = 该条款；
   宿主实现对条款写，测试对条款验。
2. **宿主新增序列化器**（PiniCore Parser 层）：对模块 AST **直读**发射结构串，⛔ 不做任何文本再解析；
   CLI `parse` 分支加 `--sig` 形态（独立输出 SIG 行，不带 flag 时行为零变化）。
3. **自举侧判据④改读宿主 SIG 行**：语言侧抽取实现（buildSigs / selectMainBlock 及两个词表函数，
   约 250 行）删除；驱动加宿主 CLI 证据源形态；判据④ 只剩比对。
4. **旧壳 awk 抽取标退役**（只标记、不删除——删除随退役批点名）。

## 3. 规范词表的收口（本件最关键的部分）

结构串的词表以**自举渲染器的行名**为规范形态（两份现存实现都从它的输出抽取，期望值由它派生）。
收口时查出并钉死三处易漂点：

1. **宿主自身显示与规范形态分歧处，以条款为准**：宿主 AST 打印把 `Self` 类型关键字显示为 `Self`、
   数组/字典/集合字面量显示为 `array:`/`dictionary:`/`set:`、成员访问拆出 `object:` 行；
   规范形态分别是 `own`、`arrayLiteral:`/`dictionaryLiteral:`/`setLiteral:`、成员名头部内联。
   序列化器按条款发射，⛔ 不沿用宿主打印层。
2. **函数字面量的声明头名为空**（匿名性质）；宿主 AST 里的占位名不进视图。
3. **无标签实参行形如 `arg []:`（带冒号）**，其元素取整行文本——该形态由「行名不在集合、
   行尾冒号后无空格」的规则组合决定，是规则推出来的，不是特例。

## 4. 代价与遗留（如实登记）

- **判据④ 的被测方变化**：切换后 ④ 判的是**宿主 parser + 序列化器**对规范的符合性；
  自举 parser 层的优先级/结合性判别退出常跑面。残留覆盖：树形良构与未渲染哨兵、声明面头行序列与
  五条定向判别式（均仍读自举层产物）、壳内逐夹具判族（随自举入格批迁移）、层过种子判据、
  自举原生构建门。语料件头显式登记该变化。
- **跨侧一致性的未覆面**：类型注解文本与浮点展示的跨侧一致性，由一次性三方对照
  （宿主 SIG ⇄ 壳侧 awk ⇄ 语言侧移植，prec-probe 全语句 + 可扩夹具）背书；
  该对照是过渡态证据，⛔ 不是常设门禁。
- **词表演进走变更治理**：集合成员增减、规则修订均属语言面变更。

## 5. 退役链

- 壳侧 awk 抽取：宿主件验证通过（三方对照一致）⇒ 标退役；删除随退役批，⛔ 不在本批自行删除。
- 语言侧抽取实现：判据④ 改读宿主 SIG 行当批删除（约 250 行）。
- 退役判据 = 「同一程序两侧读数逐字节相同」在过渡对照中成立，且改读后判据④ 绿。

## 6. 影响面与破坏性

| 面 | 破坏性 | 理由 |
|---|---|---|
| 语言层 | **否** | 纯增量的派生视图条款；无既有构造的语义变化 |
| 宿主 CLI | **否** | `--sig` 为 additive flag；不带 flag 时 `parse` 行为零变化 |
| 自举侧 | **否** | 判据④ 换读数来源（期望值不变）；被测方变化已登记 |
