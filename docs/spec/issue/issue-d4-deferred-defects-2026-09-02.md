## Def-1 · ImportInjectionTests 的 dup2 stdout 捕获与 XCTest 冲突（**本批已回避**）

- 症状：`swift test --filter ImportInjectionTests` 构建后零输出、秒退（exit 0），测试体未执行；带 dup2 stdout 重定向的用例疑似劫持 XCTest 自身输出/报告机制（IOTests 同款模式在既有套件中可用，差异点待查——IOTests 捕获后恢复，本用例 defer 恢复但 XCTest 或在其间读取 stdout）。
- 已回避：删除依赖 dup2 的两个用例（裸调用端到端 / 限定调用端到端），保留 4 个纯分析器用例（冲突三类 + 弱警告）。裸调用行为由 CLI 六场景实测覆盖（`/tmp/d4demo`：裸调用输出、`_别名.符号` 限定输出、非 `_` 裸调用 E3-002、注入 vs 本地 E3-013、注入 vs 注入 E3-013）。
- 消化方向：做一个「子进程跑 pini CLI 断言 stdout」的测试基建（对齐 ExamplesRunTests 的思路），替代进程内 dup2；届时恢复两个端到端用例。

## Def-2 · 跨模块注入传递（v1 边界，代码注释已记录）

## Def-3 · 单文件路径无语义检查（既有行为，非本批引入）
