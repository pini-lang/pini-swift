# Pini 参考文档

## 第 1 章 引言

### 1.1 概览

Pini 是一门静态类型、行敏感、缩进敏感、组合式的系统编程语言。它面向嵌入式与插件派发场景，以 ARC 管理引用类型，以结构化并发组织异步任务，以单层 IR 服务多后端。

**设计定位**：
- 不替代 C/Rust 的零成本层
- 服务逻辑层、状态机、规则引擎、插件
- 与 C 互补，通过 FFI 复用 C 生态

**核心前提**：
- 无全局可变状态
- 无继承、无动态分派
- 无反射、无元编程
- 无所有权、无借用
- 字段类型必须具体
- 特征只作约束，不作类型
- 部分信任开发者

**稳定性标记**：本参考逐节标注 `[Stable]` / `[Provisional]` / `[Experimental]` / `[Deprecated]`。四个级别的含义与兼容性承诺由 `pini-spec-v0.md` 定义——本参考只标注，不复述。

### 1.2 文档约定

- 代码示例使用 Pini 语法
- 标注 `[Stable]`、`[Provisional]`、`[Experimental]` 的构造按对应级别对待
- 跨文件引用只提文件名，不引章节号

### 1.3 术语表

| 术语 | 定义 |
|---|---|
| **ARC** | 自动引用计数。对象维护强引用计数，计数归零时释放 |
| **object** | 引用类型。由 ARC 管理，绝对最终，不可继承，不可组合 |
| **struct** | 值类型。复制时字段槽位独立 |
| **enum** | 标签联合。同构 Enum（无载荷）或 Tagged Union（有载荷） |
| **特征（trait）** | 方法签名集合。只作泛型约束，不作类型 |
| **Raw** | C 兼容类型标记。标量、纯值 struct、元组、指针自动实现 |
| **弱引用（WeakRef）** | 不增加计数的引用。对象销毁后自动置 nil |
| **无主引用（UnownedRef）** | 不增加计数、不跟踪存活的引用。仅在 unsafe 领域可用 |
| **懒加载（LazyRef）** | 首次访问时执行初始化闭包并缓存结果 |
| **COW** | 写时复制。复制时共享存储，写入时若共享则克隆 |
| **结构化并发** | 任务树模型。父子任务有明确生命周期边界 |
| **await** | 异步函数体内挂起等待子任务 |
| **wait** | 同步上下文阻塞等待 Future |
| **detach** | 派发非结构化任务，脱离父任务树 |
| **AsyncDeinit** | 异步清理。在结构化作用域退出时自动调度 |
| **部分信任开发者** | 编译器做可证明的检测与警告，不可证明处交给开发者 |
| **单层 IR** | 编译器中端只有一套 IR，服务于所有后端 |
| **SCC** | 强连通分量。用于类型级环检测与递归检测 |
| **归约计数** | 调度公平性机制。每执行 N 条指令检查是否切换任务 |

### 1.4 性质与依据

- **性质**：**语言面描述**的权威载体——覆盖词法、类型、声明、表达式、语句、内存模型、并发模型、FFI 与 unsafe、模块系统、错误模型、运行时与执行、形式文法。
- **在事实源层级中的位置**：由 `pini-spec-v0.md` 的「事实源层级与权威关系」规定，要点三条：

  2. 达到稳定程度的成果**递交本参考沉积**，本参考因此偏向稳定、变更频率低；
  3. 两者对同一构造的表述若不一致，**以 `pini-spec-v0.md` 为准**。
- **本参考不含**：工程与治理条款——事实源层级、版本演进、证据协议、缺口台账、破坏性变更政策、测试与注释标准、诊断码权威映射；其权威在 `pini-spec-v0.md`，本参考不复述。
- **变更方式**：改动先在规范侧发生；本参考随 `pini-spec-v0.md` 的变更治理流程同步。各条的裁决依据登记在 `docs/spec/adr/`。
- **与设计意图稿的关系**：`docs/Pini草稿.md` 只承载设计意图与理由（不随本仓分发）；它与本参考不一致时，以本参考为准。

## 第 2 章 词法结构

### 2.1 源文件与编码 `[Provisional]`

- 源文件使用 **UTF-8** 编码。
- 不接受 BOM。
- 换行符：`\n`（Unix 风格）；`\r\n` 在读取时归一化为 `\n`。

### 2.2 行结构 `[Provisional]`

- 语言**行敏感**：每行行尾产出 1 个 NEWLINE 记号。
- 行内空白（空格）在词法层跳过。
- 空行与注释行**透明**：不参与块边界判定。

### 2.3 缩进 `[Provisional]`

**只允许空格缩进**；制表符报错。

**缩进栈**：
- 行首缩进大于栈顶 → push + INDENT
- 行首缩进小于栈顶 → 逐层 pop + DEDENT
- 行首缩进等于栈顶 → 无记号

**缩进宽度**：不作强制规定，但同一文件内必须一致。

**强制缩进**：函数体（含顶级函数）必须缩进 ≥1 层。

**块类型**：块边界由三个维度共同决定，三者可以叠加。

**① 缩进块**（函数体、控制流子块、缩进的声明块体）：

- INDENT 开启、DEDENT 闭合；
- **空行与注释行透明**（不闭块）。

**② 顶格块**（四类块头 `(名)` `{名}` `[名]` `<名>` 的体，含扩展块）：

- 体行**可顶格或缩进**（两种写法均合法）；
- **空行与注释行透明**；
- 闭合于**下一个顶级声明的起点**——块头、`名称|func`、import/export 块；
- 体内**仅接受该块的合法行**：字段块内出现裸语句 → **E2-001**。

**③ 括号内记号流**：

- 最内层未闭合括号为**普通括号**时，括号内 **NEWLINE 等同空白、缩进不参与**（括号深度即结构）：行尾不发 newline 记号，行首不发 INDENT/DEDENT；
- **块携带括号**是例外：开括号后**同一行**紧跟块开启关键字 `func`（原地调用 IIFE 与实参位函数字面量的包裹形态），其内部布局**完全照常**（newline/INDENT/DEDENT 照常发射，与单行形态同一机制）；
- 四个括号对出现在**行首**时是块声明定界符（见 §2.9），块头单行配平，不受抑制影响。

**已裁边界**（刻意钉下的，不是疏漏）：

| 边界 | 裁定 |
|---|---|
| `<` `>` | **不参与**括号深度跟踪——泛型实参维持单行；比较运算 `a < b` 与泛型实参同形，词法层不可消歧 |
| 未闭合括号到 EOF | **宽松静默**，不报错（ADR-021：词法层保持零错误契约，畸形诊断后移到解析 / 语义阶段） |
| 不匹配的 closer | **一律弹栈**（限制级联效应） |
| 反引号转义 | `` `func` `` 不构成块携带 |
| 块携带判定前瞻 | **仅限同行** |

**空行与注释行透明**：不闭块。

> **判据**：上述块文法在「缩进块 / 顶格块 / 括号内记号流」三维度上按六探针实测钉定——缩进体、顶格与缩进字段块的空行透明、下一顶级声明闭合、裸语句 E2-001、扩展块；并以差分实验复核（字段块内含空行时，宿主与自举的 token 流 MATCH）。

### 2.4 注释 `[Provisional]`

```
; 行注释，持续到行尾
# 文档注释，行首，持续到行尾；可能退化为行注释
```

`;` 和 `#` 均在词法层被跳过，不产出记号。

### 2.5 标识符 `[Provisional]`

**首字符**：Unicode 字母（`\p{L}`）或下划线。

**后续字符**：Unicode 字母、Unicode 数字属性字符、下划线。

**`_` 前缀**：表示访问控制（见 §4.10）。

**反引号转义**：

```
`名称`
```

允许关键字作标识符：

```
let `if` = 1     ; 合法，`if` 作标识符
```

反引号内可为任意标识符字符。未闭合或空内容回退为单字符标识符。

### 2.6 关键字 `[Provisional]`

```

while step for in
try return break continue

nil capture await wait
unsafe test foreign detach
scope pass
```

共 34 个。

**反引号转义**：关键字可用反引号包裹作标识符。

**`scope`**：保留但不再使用。

```

| 记号 | 角色 |
|---|---|
| `\|` | 按位或 / 声明修饰分隔符 / 标签分隔符 / 联合类型分隔符 |

| `^` | 按位异或 / 结果类型糖 / 右值解包前缀 |

| `?` | 可选类型前缀 |
| `@` | 保留待用 |

**关联记号的方向语义**：`=` 与 `:` 各有单一方向，跨构造一致。

| 记号 | 方向 | 出现处 |
|---|---|---|
| `=` | **值的注入方向** | 实参标签 `f(a = 1)`、字典条目 `["k" = 1]`、元组标签 `(a = 1,)`、默认参数 `n: I32 = 1`、枚举具名构造 `E(x = 1)` |
| `:` | **类型与块的标注方向 + 值的取出方向** | 类型标注 `n: I32`、块开启 `if c:`、match 具名绑定 `case A(x: v):` |

旧写法 `f(a: 1)` / `[k: v]` / `(a: 1,)` / `E(x: 1)` **已废弃**，解析器给迁移提示。

切片 `a[i:j]` 的 `:` 是**分隔符**，不属关联记号，不受本规则约束。

### 2.9 行首消歧 `[Provisional]`

`(` `[` `{` `<` 在**行首**（NEWLINE 后）触发顶级声明分派：

| 行首记号 | 声明类型 |
|---|---|
| `(` | 结构块 |
| `{` | 对象块（糖） |
| `[` | 枚举块 / 对象块 |
| `<` | 特征块 |
| `((` | 结构扩展块 |
| `{{` | 对象扩展块 |
| `[[` | 枚举扩展块 |
| `<<` | 特征扩展块 |

同一记号在表达式/类型位置有不同语义：

| 记号 | 行首 | 非行首 |
|---|---|---|
| `(` | 结构声明 | 元组 / 优先结合 |
| `[` | 枚举/对象声明 | 数组 / 字典 |
| `{` | 对象声明糖 | 集合 |
| `<` | 特征声明 | 泛型实参 / 比较 |

**消歧锚点**：当前以「是否出现在行首」为**唯一**规则。该锚点**已知脆弱**——同一记号靠位置分派，位置判断一错则整类声明走岔；本版本固定该法，未来若换算法属破坏性变更。

四类块声明的字段、扩展、组合与初始化规则见 §3.3–§3.5、§4.3–§4.6；本节只给分派形式（行首记号 → 声明类型），语义在那里。

## 第 3 章 类型系统

### 3.1 标量类型 `[Provisional]`

与 Rust 对齐：

| 类型 | 宽度 | 范围 |
|---|---|---|
| `I8` | 8 位有符号 | −128 到 127 |
| `I16` | 16 位有符号 | −32768 到 32767 |
| `I32` | 32 位有符号 | −2³¹ 到 2³¹−1 |
| `I64` | 64 位有符号 | −2⁶³ 到 2⁶³−1 |
| `U8` | 8 位无符号 | 0 到 255 |
| `U16` | 16 位无符号 | 0 到 65535 |
| `U32` | 32 位无符号 | 0 到 2³²−1 |
| `U64` | 64 位无符号 | 0 到 2⁶⁴−1 |
| `F32` | 32 位浮点 | IEEE 754 单精度 |
| `F64` | 64 位浮点 | IEEE 754 双精度 |
| `Bool` | 布尔 | `true` / `false` |
| `Char` | Unicode 标量值 | 0 到 0x10FFFF |

**算术溢出语义**：待定（当前与宿主一致）。

### 3.2 指针类型 `[Experimental]`

`*T` 原始指针。

**约束**：
- `T` 必须是 C 兼容类型：标量、纯值 struct、其他指针
- 禁止 `object` 或含 `object` 字段的复合类型
- 与 ARC 完全隔离

**指针算术**：

| 形式 | 语义 |
|---|---|
| `p + n` | 按元素大小偏移，`n * sizeof(T)` 字节 |
| `p - n` | 按元素大小反向偏移 |
| `p2 - p1` | 返回元素个数 |
| `p 字节偏移 n` | 按字节偏移（显式） |

必须在 `unsafe` 上下文。

**读写**：

```
unsafe 加载(p)        ; 读 *p
unsafe 存储(p, 值)    ; 写 *p
```

**取地址**：

```
unsafe &变量          ; 取地址
```

**示例**：

```
[libc|foreign]
malloc|unsafe(大小: I64,) -> *I8

let 缓冲 = unsafe malloc(1024)
defer unsafe free(缓冲)
unsafe 存储(缓冲 + 0, 42)        ; 按元素偏移
unsafe 存储(缓冲 字节偏移 4, 43)  ; 按字节偏移
```

### 3.3 结构类型 `[Experimental]`

`(名称)` 值类型。

**字段声明**：

```
(点)
x: I32 = 0
y: I32 = 0
```

- 字段名在前，类型在后
- `_` 前缀字段为私有（类型内可见）
- 默认值直接写，不需要构造函数

**组合（Go 组合语义）**：

```
(基类)
字段A: I32 = 0

(派生类)
基类                    ; 内嵌组合
字段B: I32 = 0
```

内嵌类型字段提升到外层：

```
let 对象 = 派生类()
对象.字段A    ; 直接访问，等价于 对象.基类.字段A
```

**方法**：必须在扩展块中声明（见 §4.7）。

**值语义**：复制时字段槽位独立；若字段含 object，则 object 引用共享。

### 3.4 对象类型 `[Provisional]`

`{名称}` 引用类型，或 `[名称|object]`。

**字段声明**：

```
{计数器}
数值: I32 = 0
```

- 绝对最终，不可继承，不可组合
- ARC 管理
- `_` 前缀字段为私有

**ARC 管理**：引用复制增加计数，计数归零释放。

**对象相等（身份相等）** `[Experimental]`：

```
let a = 创建对象()
let b = a
a == b        ; true，指向同一实例

let c = 创建对象()
a == c        ; false，不同实例
```

结构相等需显式方法：

```
{配置}
值: I32 = 0

相等|self(其他: 配置,) -> Bool:
    return self.值 == 其他.值
```

### 3.5 枚举类型 `[Experimental]`

`[名称]` 或 `[名称|enum]`。

**同构 Enum（无载荷）**：

```
[颜色]
红
绿
蓝
```

布局：`I8`（3 个值）。标签类型固定 `I8`。

**Tagged Union（有载荷）**：

```
[形状]
圆(点, F64,)
矩形(点, 点,)
点
```

布局：

```
{ 标签: I8, 载荷: max(圆载荷, 矩形载荷) }
```

无载荷用例不占载荷空间。

**优化**：

| 优化 | 条件 |
|---|---|
| 标签优化 | 无载荷用例，纯整数 |
| 空指针优化 | `Optional<Object>` 用空指针 |
| 载荷优化 | 无载荷用例不占载荷空间 |

**构造**：

```
let 形 = 形状.圆(原点, 3.14)
```

**匹配**：

```
match 形:
    case 形状.圆(_, 半径):
        return 3.14 * 半径 * 半径
    case 形状.矩形(左上, 右下):
        return 宽(左上, 右下) * 高(左上, 右下)
    case 形状.点:
        return 0.0
```

### 3.6 元组类型 `[Provisional]`

**位置元组**：

```

```

**命名元组**：

```

```

**带值元组**：

```

```

**空元组**：

**访问**：

**解构**：

```

### 3.7 集合类型 `[Provisional]`

| 类型 | 语法 | 语义 |
|---|---|---|
| 数组 | `[T,]` | 默认变长，堆分配 |
| 字典 | `[K:V,]` | 散列 |
| 集合 | `{T,}` | 散列 |
| 定长数组 | 走内置 | 编译期固定 |

**定长数组走内置**：用户不在类型位置写整数；定长数组由内置类型与初始化表达式表达。

**字面量**：

```
[1, 2, 3,]              ; 数组
["k" = 1, "j" = 2,]     ; 字典
{1, 2, 3,}              ; 集合
```

**空字典**：无字面量形态；用类型构造 `字典<K, V>()`。

**下标**：见 §5.6。

### 3.8 可选类型 `[Provisional]`

`?T` ≡ `Optional<T>`

```

let y: I32? = 42
```

- `.some(值)` / `.none`
- `nil` = `.none`
- 强制解包：`值!`

**构造**：

```

let b: I32? = nil
```

**解包**：

```
if let 值 = 可选值:
    ...
```

### 3.9 结果类型 `[Provisional]`

`^T` ≡ `Result<T, E>`

```
let r: ^I32 = .ok(42)
let e: ^I32 = .err(Error())
```

- `.ok(值)` / `.err(错)`
- `^右值` 解包糖 ≡ `try 右值 else err: return err`

**函数返回 Result**：

```
读取文件(路径: String,) -> (^String,):
    return .err(Error())
```

```
(I32, String,) -> (F64,)           ; 同步函数
(I32, String,) => (F64,)           ; 异步函数
```

**空返回**：

```

```

**单返回糖**：

```

### 3.11 泛型 `[Provisional]`

```

```

**约束**：

```

## 第 4 章 声明

### 4.1 模块结构 `[Provisional]`

**顶级结构**：单行标识符声明 与 复合块**交替**。

```
; 类型声明
(点)
x: I32 = 0

; 函数声明
距离|func(a: 点, b: 点,) -> F64:
    ...

; 另一个类型声明
(线)
起点: 点 = ...
终点: 点 = ...
```

**块边界隐式关闭**：块由下一个顶级声明隐式关闭，无 `}` 结束符。顶格块与缩进块的三个维度、体行的合法形态见 §2.3；体内仅接受该块的合法行（字段块内裸语句 → E2-001）。

**顶级声明类型**：

| 记号 | 声明 |
|---|---|
| `(名称)` | 结构块 |
| `{名称}` | 对象块（糖） |
| `[名称]` | 枚举块 |
| `[名称\|object]` | 对象块 |
| `<名称>` | 特征块 |
| `((名称))` | 结构扩展块 |
| `{{名称}}` | 对象扩展块 |
| `[[名称]]` | 枚举扩展块 |
| `<<名称>>` | 特征扩展块 |
| `名称\|func(...)` | 裸函数 |
| `[名称\|import]` | 导入块 |
| `[名称\|export]` | 导出块 |
| `[名称\|foreign]` | 外部函数块 |

### 4.2 导入与导出 `[Provisional]`

#### 导入块

```
[文件名|import]
别名 = "模块路径"
_隐式 = "模块路径"
```

- 块头名 = 当前文件名（去 `.pini` 后缀）
- `别名 = "路径"`：显式别名，使用时 `别名.符号`
- `_隐式 = "路径"`：注入导入，目标模块 public 符号进入本文件裸名空间
- 非 `_` 别名必须限定调用
- `_` 别名可裸调用，也可 `_别名.符号` 限定调用

#### 导出块

```
[文件名|export]
公开名 = 原符号
_私有名 = 原符号
```

- 块头名 = 当前文件名
- `公开名 = 原符号`：提升私有符号为公开
- `_私有名 = 原符号`：抑制导出

#### 依赖规则

- `import` 即依赖
- 模块依赖 = 该模块所有文件 import 的并集
- 依赖图无环
- 仅 `public` 可跨模块引入

```

    return ...

### 4.7 扩展块 `[Experimental]`

|---|---|

| `[[名称]]` | 枚举 |

**约束**：

- 不允许自由函数

### 4.8 函数声明 `[Experimental]`

**不支持重载**。同名函数重复定义报错。

**签名**：

```

```

**示例**：

```

    let dx = a.x - b.x
    let dy = a.y - b.y
    return sqrt(dx * dx + dy * dy)
```

**修饰符**：

| 修饰符 | 含义 |
|---|---|
| `\|self` | 本身方法 |
| `\|own` | 本型方法 |
| `\|test` | 测试函数 |
| `\|unsafe` | 不安全函数 |

**默认参数**：

```

    ...
```

**泛型函数**：

```
映射<T, U>(s: [T,], f: (T,) -> U,) -> ([U,],):
    ...
```

**函数体必须缩进 ≥1 层**。

### 4.9 变量声明 `[Provisional]`

```
var x = 1        ; 可变
let y = 2        ; 不可变
```

**类型标注**：

```
var x: I32 = 1
let y: String = "hello"
```

**解构**：

```
var (a, b) = 元组
let (t, e) = some_thing_error()
```

**无初始化器**：

```
var x: I32 = 0
```

### 4.10 访问控制 `[Provisional]`

| 级别 | 触发条件 | 可见范围 |
|---|---|---|
| private | 符号以 `_` 开头 | 当前类型内部 |
| internal | 非 `_` 开头，文件名 `_` 开头 | 当前文件 |
| package | 非 `_` 开头，目录名 `_` 开头 | 当前包 |
| public | 均非 `_` 开头 | 全局 |

**取最严格者为准**。

**跨模块引入门槛**：仅 `public` 可被跨模块引入。

**`_` 单一语义**：退出默认表面。

| 位置 | 含义 |
|---|---|
| 声明位：符号 `_名称` / 文件 `_名称.pini` / 目录 `_名称/` | private / internal / package（按 `_` 落在哪一层，见上表） |
| 导出表 `_C = 符号` | 抑制导出 |
| 导入表 `_B = "路径"` | 注入导入 |
| 模式位 `case _:` | 通配 |

**为何复用 `_` 而不新增关键字**：Pini 中每个独特关键字的通用块都有各自不同的内部语法——新增关键字即新增一套块语法、扩大语法不一致面。复用 `_` 作为贯穿多声明语境的「退出默认表面」修饰符，与既有的「`_` 前缀即修饰」约定同轴，故不另立 `implicit` 之类关键字（弃用方案 B：为导入隐式性单设关键字）。

**示例**：

```
(计数器)
名称: String = "秒表"
_周期: I8 = 60
数值: I32 = 0
```

`_周期` 为 private，仅类型内部可见。

```

复合赋值脱糖为 `x = (x op 值)`。

**约束**：仅语句级，不参与表达式链。

### 6.3 控制流 `[Provisional]`

#### if / elif / else

```
if 条件:
    语句块
elif 条件:
    语句块
else:
    语句块
```

`elif` 向前就近匹配同级 `if` / `elif`；`else` 向前就近匹配同级 `if` / `elif`。

**单行形式**：

```
if 条件: 单行语句
```

#### while / step

```
while 条件:
    语句块
step:
    步进语句块
```

`step` 块在每个循环末尾执行。

#### for-in

```
for (模式元组,) in 集合值:
    语句块
step:
    步进语句块
```

模式元组与集合元素一一对应绑定，`_` 占位忽略。

```
for (值, 索引) in 数组:
    print(索引, 值)
```

#### match / case

```
match 值:
    case 模式:
        语句块
    case 模式:
        语句块
    case _:
        语句块
```

- `case` 缩进进 `match` 子块
- 通配兜底为 `case _:`
- 无 `default:`
- 枚举 match 缺变体且无 `case _:` → 编译期错误 `nonExhaustiveMatch`
- 字面量 match 静态不检查穷尽性

**枚举解构**：

```
match 形状:
    case 形状.圆(_, 半径):
        return 3.14 * 半径 * 半径
    case 形状.矩形(左上, 右下):
        return ...
    case 形状.点:
        return 0.0
```

**同名 case 消歧**：按被匹配值的枚举类型解析父枚举；跨枚举同名 case 时不得按名字全局反查。

#### 标签 `[Provisional]`

标签语法：`标签|控制流关键字`

```
outer|while 条件:
    let 索引 = 0
    inner|while 索引 < len(列表):
        let 项 = 列表[索引]
        if 条件:
            break outer
        else:
            continue inner
```

`break 标签` / `continue 标签` 按标签名定向。

标签为裸标识符，无 sigil。

### 6.4 try 语句 `[Provisional]`

**语句位**：

```
try 表达式 else 错误名: 控制流语句
try 表达式 else 错误名:
    语句块
```

**示例**：

```
try 读取文件(路径) else err: return err

try 读取文件(路径) else err:
    print("读取失败")
    return err
```

**单行 handler 限制**：仅 `return` / `break` / `continue` / `pass`。

**块形式要求**：须以控制流语句终止。

见 §5.10 表达式位。

### 6.5 defer `[Experimental]`

**相邻单行形式**：

```
defer 清理语句
```

**块形式**：

```
defer:
    清理语句块
```

**语义**：块退出前按 LIFO 顺序执行。

**示例**：

```
let 文件 = 打开文件(...)
defer 关闭文件(文件)

let 缓冲 = 分配(...)
defer 释放(缓冲)
```

块形式作用域独立（内部绑定不外泄）。

### 6.6 return / break / continue `[Provisional]`

**return**：

```
return
return 值
```

**break**：

```
break
break 标签
```

不携带值。

**continue**：

```
continue
continue 标签
```

仅循环标签有效。

### 6.7 pass `[Provisional]`

no-op 占位语句。

```
pass
```

**用途**：

| 场景 | 示例 |
|---|---|
| 占位空块 | `if 条件: pass` |
| match 分支占位 | `case 已读: pass` |
| 显式吞掉错误 | `try f() else e: pass` |
| 桩函数 | `func 尚未实现(): pass` |
| trait 默认方法空实现 | `<<T>>` 内 `方法(): pass` |

**语义边界**：

- 值为 `null`，不是有意义的表达式值
- 不终止控制流
- 与 match 穷尽性无关

### 6.8 detach `[Provisional]`

```
detach 异步调用
```

**语义**：将子任务从父 scope 剪枝，主动退出所有权。

- 结局不再归父所有
- 不触发失败上浮
- 不被 B2-2 取消
- fire-and-forget 的唯一合法出口

**示例**：

```
detach 后台任务(参数)
```

### 6.9 capture `[Provisional]`

```
capture 外部标识符
```

**位置**：匿名函数体内部顶层语句位。

**规则**：

- 每行恰一个外部标识符
- 可散落多条，不要求集中
- 语句序上须先于所列名字在体内的首次使用（E3-008）
- 目标须是创建点外层的局部变量（E3-009）
- 位置仅限匿名函数缩进体顶层语句位（E2-007）

**示例**：

```
let 阈值 = 10
let 回调 = func (x: I32,) -> Bool:
    capture 阈值
    return x > 阈值
```

**不支持**：

- 捕获表达式
- `self` 由 `|self` 修饰符表达，不进 capture 列表

## 第 7 章 内存模型

### 7.1 ARC 引用计数 `[Provisional]`

**对象头**：

```
{ 强引用计数, 弱引用计数, 类型标识, 弱引用链 }
```

**计数规则**：

| 操作 | 计数变化 |
|---|---|
| 引用复制 | 强计数 +1 |
| 引用丢弃 | 强计数 −1 |
| 计数归零 | 释放对象 |

**释放**：

- 调用 `deinit`（若定义）
- 清空弱引用
- 释放内存

**延迟释放队列**：避免析构风暴。计数归零时不递归释放字段，而是入队，迭代释放。

**原子性**：

| 场景 | 计数操作 |
|---|---|
| 单任务 | 非原子 |
| 跨任务共享 | 原子 |

**示例**：

```
{节点}
值: I32 = 0

let a = 节点()      ; 计数 = 1
let b = a           ; 计数 = 2
b = 节点()          ; 原节点计数 = 1
a = 节点()          ; 原节点计数 = 0，释放
```

### 7.2 弱引用 `[Provisional]`

**类型**：`WeakRef<T>`

**创建**：

```
let 快照 = weak 对象
```

`weak 对象` 是右值表达式，求值为 `WeakRef<T>`。

**字段**：

```
{节点}
_父: WeakRef<节点> = .none
```

字段类型用 `WeakRef<T>` 表达。

**访问**：

```
快照.value         ; 返回 Optional<T>
if let 目标 = 快照.value:
    目标.方法()
```

**语义**：

| 操作 | 行为 |
|---|---|
| 创建 | 不增加强计数，注册到对象弱引用链 |
| 访问 | 返回 `Optional<T>`；对象销毁后 `.none` |
| 断开 | `WeakRef<T>.none` 或字段置 `.none` |
| 对象销毁 | 弱引用自动置空 |

**闭包捕获**：

```
let 弱节点 = weak 节点
节点.绑定回调(func () -> ():
    capture 弱节点
    if let 目标 = 弱节点.value:
        目标.方法()
    return
)
```

`capture` 只负责可见性，强弱由被捕获标识符类型决定。

**编译器优化**：能证明对象必然存活时，优化为 `UnownedRef` 语义（去旁表、去原子、直接访问）；证明失败回退完整 `weak`。见 §7.4。

### 7.3 懒加载 `[Provisional]`

**类型**：`LazyRef<T>`

**构造**：

```
let 缓存 = LazyRef(func () -> T:
    return 计算()
)
```

或：

```
let 缓存 = LazyRef<T>(func () -> T:
    return 计算()
)
```

**访问**：

```
缓存.value        ; 同步阻塞，返回 T
```

**语义**：

| 操作 | 行为 |
|---|---|
| 首次访问 | 执行初始化闭包，缓存结果 |
| 后续访问 | 返回缓存值 |
| 多线程首访 | 仅一个线程执行初始化 |
| 复制 | 引用语义，共享同一 box |

**引用语义**：复制 `LazyRef<T>` 时共享同一 box，不重复初始化。

### 7.4 无主引用 `[Experimental]`

**类型**：`UnownedRef<T>`

**创建**：

```
let 快照 = unsafe UnownedRef(对象)
```

**访问**：

```
unsafe 快照.方法()
```

**约束**：

- 仅在 `unsafe` 上下文
- 持有、传递、比较安全
- 解引用、调用、访问字段需要 `unsafe`
- 不增加计数
- 不跟踪存活
- 对象销毁后访问 UB

**与 `*T` 的区别**：

| 维度 | `*T` | `UnownedRef<T>` |
|---|---|---|
| 指向 | C 兼容内存 | ARC 对象 |
| 计数 | 无 | 无 |
| 跟踪 | 无 | 无 |
| 类型安全 | 弱 | 强 |
| 与 ARC | 隔离 | 参与类型系统 |

**编译器优化关系**：编译器把 `weak` 优化为 `unowned` 语义是编译器证明；用户手写 `UnownedRef` 是用户声称。

### 7.5 COW `[Experimental]`

**范围**：仅集合 COW（数组、字典、集合），与 Swift 经验一致。

**语义**：

| 操作 | 行为 |
|---|---|
| 复制 | 共享底层存储，增加存储计数 |
| 只读访问 | 无复制 |
| 写入且唯一 | 原地修改 |
| 写入且共享 | 克隆存储，修改副本 |

**示例**：

```
var a = [1, 2, 3,]
var b = a           ; 共享存储
b[0] = 10           ; 写入触发克隆，a 不变
```

**用户 struct**：默认值复制，不 COW。

**编译器优化**：检测到大 struct 时可选 COW。

**开发者标注**：可显式 `@cow` 强制 COW，或 `@inline` 强制内联。

**与 object 字段的关系**：COW 只作用于值字段存储；object 字段是引用，复制时 retain，不参与 COW。

### 7.6 循环检测 `[Provisional]`

**仅警告**，不阻止编译。

**检测对象**：类型级强引用图 SCC。

**层级**：

| 层级 | 环形成方式 | 检测机制 |
|---|---|---|
| L1 | 直接双向字段赋值 | 类型图强连通分量检测 |
| L2 | 本身方法内闭包捕获 self 存入字段 | 过程内语法扫描 |
| L3 | 跨方法间接赋值 | 类型级边摘要 + 调用点合并 |
| L4 | 闭包经集合传递 | 集合不存对象与闭包时消除 |
| L5 | 运行时数据驱动 | 动态数据仅为值类型时消除 |

**关停位置**：

| 关停位置 | 触发条件 |
|---|---|
| 存在类型字段边 | 字段类型含特征类型 |
| 存在类型参数 | 参数类型含特征类型 |
| 集合持有对象 | 集合元素为对象 |
| 通道传对象 | 通道元素为对象 |
| 动态数据构建对象引用 | 运行时数据含对象 |
| unsafe 边界 | 指针操作、FFI |

**处理**：

- 编译期警告
- 建议使用 `WeakRef`
- 不自动断环
- 不阻止编译

**复杂度**：

| 阶段 | 复杂度 |
|---|---|
| 类型图构建 | O(V+E) |
| L1 强连通分量检测 | O(V+E) |
| L2 闭包扫描 | O(ΣS+ΣC) |
| L3 函数摘要 | O(ΣF+ΣC) |
| L3 调用点合并 | O(ΣP) |
| 全程序汇总 | O(V+E+ΣF+ΣC+ΣP+W) |
| 增量编译 | O(变化量) |

### 7.7 析构 `[Provisional]`

**`deinit`**：

```
{资源持有者}
_句柄: *I8 = nil

deinit|self() -> ():
    if self._句柄 != nil:
        unsafe free(self._句柄)
    return
```

**硬不变量**：不复活 `self`。

- 不把 `self` 存入全局、缓存、闭包、字段、任务
- 默认警告，不阻止编译
- 严格模式 opt-in 可升级

**信任开发者**：不会在析构中做长耗时操作。

**`AsyncDeinit`**：

```
{异步资源持有者}
_句柄: 异步句柄? = nil

asyncDeinit|self() => ():
    if let 句柄 = self._句柄:
        await 句柄.关闭()
        self._句柄 = nil
    return
```

**调度**：

| 场景 | 行为 |
|---|---|
| 结构化作用域退出 | 自动调度 |
| `detach` 任务 | 不自动，责任交开发者 |
| 逃逸对象 | 不自动，责任交开发者 |

**与计数归零的关系**：

- 计数归零只触发 `deinit`
- `AsyncDeinit` 由结构化作用域退出触发
- 对象在作用域退出前计数归零：运行时保留对象壳等待异步清理

## 第 8 章 并发模型

### 8.1 结构化并发 `[Stable]`

**任务树模型**：父子任务有明确生命周期边界。

**核心规则**：

| 规则 | 说明 |
|---|---|
| B2-1 取消树 | 父强持有子，子弱引用父；父取消递归取消子 |
| B2-2 父返回自动取消 | 任务体结束取消未 join 且未完成的子任务 |
| 失败传播 | 未 join 失败在父返回边界上浮 |

**取消树结构**：

```
Future（父）
  ├─ 强持有 → 子 Future 1
  ├─ 强持有 → 子 Future 2
  └─ 弱引用 → 父 Future（无保留环）
```

父被取消时递归取消全部子；父已取消后新登记的子立即取消。

**join 边界**：函数体 `return` 即 scope 的显式 join 边界。

### 8.2 任务派发 `[Stable]`

#### 异步函数

```
async 函数名() => ():
    语句块
```

`=>` 标记异步函数，返回 `Future<(返回元组,)>`。

#### await

```
await 表达式
```

异步函数体内挂起等待子任务。

- 保存续体（精确恢复点）
- 释放当前 OS 线程（非阻塞）
- `Future` 决后经 executor 从精确恢复点续跑
- 已执行副作用不重跑

#### wait

```
wait 表达式
```

同步上下文阻塞等待 Future。

#### detach

```
detach 表达式
```

派发非结构化任务，脱离父任务树。

- 结局不再归父所有
- 不触发失败上浮
- 不被父返回自动取消
- fire-and-forget 的唯一合法出口

#### 示例

```
async 处理(数据: [I32,],) => (I32,):
    let 结果 = await 计算(数据)
    return 结果

main() -> ():
    let 未来 = 处理([1, 2, 3,])
    let 结果 = wait 未来
    return
```

### 8.3 取消 `[Stable]`

**协作式取消**：取消不强杀线程，于下一个挂起 / resume 边界生效。

**挂起模式检查点**：在 resume 边界统一检查。

- 任务被取消经 `onCancel` 即时唤醒
- resume 入口 `checkCancellation` 见 cancelled 即抛 `CancelError` 终结
- 即使挂起等待的 `Future` 永不 resolve / 已 `detach`，取消也即时生效

**同步/阻塞路径检查点**：循环头 / 函数入口 / 睡眠分片。

**非挂起即不可中断**：紧循环不挂起则循环中不可被打断（同 Swift）；循环头/回边检查仍保留。

**取消传播**：

```
父任务取消
  → 递归取消全部子任务
  → 子任务在下一个检查点终止
  → CancelError 经 Result 传播
```

### 8.4 错误传播 `[Stable]`

**错误即数据**：`CancelError` 经 `Result` 显式传播，不在调用栈上抛异常。

**await / wait join 结果**：`Future` 求值为 `Result`。

- 成功：`.ok(值)`
- 失败：`.err(错)`
- 取消：`.err(CancelError)`

**try-else 捕获**：

```
let 结果 = try (await 未来) else err:
    return err
```

`CancelError` 经 try-else 的 `err` 路径正常捕获、不穿透。

**失败上浮（严格结构化）**：

- 函数体 `return` 即 scope 显式 join 边界
- 未 join、未 detach、却 resolve 为 err 的子任务，其失败在边界上浮
- 若局部结果本为 `ok(v)` 则翻为 `err(aggregate)`
- 唯一有界 override，正当性来自「失败不得泄漏」

**`detach` 出口**：`detach` 的子任务不参与失败上浮。

**joinAll 聚合（fail-fast）**：

- 任一成员 `err` 立即以该 `err` 返回并取消其余未完成任务
- 成员 `cancel` 经 `onCancel` 联动取消

### 8.5 调度 `[Experimental]`

**混合式**：

| 模式 | 说明 |
|---|---|
| 协作式 | 默认，任务在 `await` 点主动让出 |
| 混合式 | 协作式 + 归约计数，长时间运行任务可被抢占 |

**配置**：

```toml
[profile.embedded]
调度 = "协作式"

[profile.embedded_fair]
调度 = "混合式"
归约阈值 = 1000
```

**归约计数**：

- 每执行 N 条字节码检查是否切换任务
- 不增加字节码指令（解释器层机制）
- 阈值可配置

**切换成本**：

| 模型 | 每指令开销 | 每次切换开销 | 公平性 |
|---|---|---|---|
| 协作式 | 0 | 10–100 ns | 差 |
| 混合式 | 1–5 ns | 100–1000 ns | 好 |

**适用场景**：

| 场景 | 推荐 |
|---|---|
| 短小任务 | 协作式 |
| 长时间运行任务 | 混合式 |
| 硬实时 | 需可预测切换 |
| 多任务公平 | 混合式 |

**挂起模式上下文还原（MUST）**：

挂起/恢复跨线程（work-stealing 复用 OS 线程）时，continuation 必须捕获并还原解释器线程上下文：

```
{ currentEnv, currentFuture, deferStack, debugDepth, callStackNames }
```

否则上下文串台。

**探针边界**：

挂起模式暂不支持泛型构造实参内的 `await` 及 `callFunctionValue` 特殊形态在含 `await` 实参下的逐形复制；此类路径报「挂起模式暂不支持」。

`joinWithin` 保持阻塞语义（见 §8.2）。

**已知限制**：

- 并发原语 `cancel` / `isCancel` / `join` / `joinAll` / `joinWithin` 的函数签名未钉住（Experimental）
- 内建错误类型 `Error()` / `CancelError()` / `Result` 的构造参数与字段细节待钉定

## 第 9 章 FFI 与 unsafe

### 9.1 unsafe 表达式 `[Experimental]`

**前缀**：

```
unsafe 表达式
```

标记单次不安全消耗点，精确控制最小不安全范围。

**作用范围**：

| 形式 | 说明 |
|---|---|
| `unsafe 函数调用(参数)` | 作用于紧随其后的单次函数调用 |
| `unsafe 指针操作` | 作用于紧随其后的指针操作 |
| `unsafe (复合表达式)` | 复合表达式需用括号 |

**示例**：

```
let 指针 = unsafe malloc(1024)
unsafe 存储(指针, 42)
let 值 = unsafe 加载(指针)
let 结果 = unsafe (加载(p) + 1)
```

**可用位置**：任何函数体内（函数、方法、测试函数、闭包）。

**已知限制**：解释器 `&` 为快照取址（写回不更新原变量），与 LLVM 端真引用语义不同。

### 9.2 |unsafe 函数 `[Experimental]`

**声明**：

```
写入内存|unsafe(目标: *I8, 数据: [I32],) -> ():
    for (值, 索引) in 数据:
        存储(目标 + 索引, 值)
    return
```

**语义**：

- 仅限自由函数（顶层或 foreign 块签名）
- 表示「调用者须保证前置条件」
- 函数体自动处于不安全上下文
- 内部无需再使用 `unsafe` 前缀

**约束**：

| 约束 | 说明 |
|---|---|
| 禁止与 `\|self` 组合 | 避免组合爆炸 |
| 禁止与 `\|test` 组合 | 同上 |
| 扩展块方法不可标 | 报错 |
| trait 签名不可标 | 报错 |
| 匿名函数不可标 | 闭包体内用 `unsafe` 消耗点 |

**调用规则**：

- 安全上下文中调用 `|unsafe` 函数需要 `unsafe` 消耗点
- `|unsafe` 函数体内可直接调用
- 闭包不继承外层函数的不安全上下文，即使定义在 `|unsafe` 函数内部

### 9.3 指针类型 `[Experimental]`

见 §3.2。

**C 兼容性约束**：

`*T` 的 `T` 必须为：

| 允许 | 说明 |
|---|---|
| 标量 | I8–I64、U8–U64、F32、F64、Bool |
| 纯值 struct | 所有字段 C 兼容 |
| 其他指针 | `*U`（U 也须 C 兼容） |

**禁止**：

| 禁止 | 原因 |
|---|---|
| `object` | ARC 管理，内存布局含对象头 |
| 含 `object` 字段的复合类型 | 同上 |
| `String` | 运行时管理 |
| `Optional<T>` | 需标签 |
| `Result<T>` | 同上 |
| 元组 | 非 C 布局 |
| 函数类型 | 非 C 布局 |

**指针算术**：

| 形式 | 语义 |
|---|---|
| `p + n` | 按元素大小偏移 |
| `p - n` | 按元素大小反向偏移 |
| `p2 - p1` | 返回元素个数 |
| `p 字节偏移 n` | 按字节偏移 |

**读写**：

```
unsafe 加载(p)
unsafe 存储(p, 值)
```

### 9.4 foreign 块 `[Experimental]`

**声明**：

```
[libc|foreign]
malloc|unsafe(大小: I64,) -> *I8
free|unsafe(指针: *I8,) -> ()
memcpy|unsafe(目标: *I8, 源: *I8, 大小: I64,) -> ()
```

**语义**：

- 声明外部 C 函数签名
- 块内函数自动视为 `|unsafe`
- 不接收内联 ABI 参数
- 继承模块级 `pini.toml` 设定的 FFI ABI（默认 `"C"`）

**FFI 配置**：

```toml
[ffi]
abi = "C"
search_paths = ["/usr/lib", "/usr/local/lib"]
libs = ["m", "pthread"]
```

| 配置 | 说明 |
|---|---|
| `abi` | 全局唯一，默认 `"C"`，子模块不可覆盖 |
| `search_paths` | 库搜索路径，分层追加 |
| `libs` | 需链接的库列表 |

**类型白名单（顶层签名）**：

| 允许 | 说明 |
|---|---|
| 标量 | I8–I64、U8–U64、F32、F64、Bool |
| `()` | void 返回 |
| `*T` | T 为标量 / 纯值 struct / 另一指针 |

**禁止**：

| 禁止 | 原因 |
|---|---|
| by-value 结构体 | Phase 2c 范围 |
| `object` | ARC 隔离 |
| `String` | 非 C 类型 |
| `Optional` / `Result` | 需标签 |
| 元组 | 非 C 布局 |
| 函数类型 | 非 C 布局 |
| `Char` | C `char` 符号性由实现定义 |

**foreign 符号作用域**：

- 文件级作用域
- 仅在同一源文件内可见
- 跨文件引用报 E5-017

**解析顺序**：

1. 原生 shim 白名单（运行时预注册）
2. 裸 C 绑定（`dlsym` 解析符号）

未命中任何类别 → 注册期 fail-fast。

**示例**：

```
[libc|foreign]
malloc|unsafe(大小: I64,) -> *I8
free|unsafe(指针: *I8,) -> ()

安全分配(大小: I64,) -> ^*I8:
    let 指针 = unsafe malloc(大小)
    if 指针 == nil:
        return .err("分配失败")
    return .ok(指针)
```

### 9.5 与 ARC 隔离 `[Experimental]`

**规则**：

- `*T` 指向的内存不是 ARC 对象
- 不参与自动引用计数
- 编译器确保 `*T` 不能指向 ARC 对象（类型约束）
- 不允许将 ARC 对象转换为 `*T`（除非经标准库安全借用函数）

**复制语义**：

| 场景 | 行为 |
|---|---|
| 复制值类型时指针浅拷贝 | 与对象引用复制类似 |
| 持有安全 | 是 |
| 解引用 | 需 `unsafe` |

**指针的初始化和释放**：

- 由用户手动保证
- 语言不提供自动管理
- 建议 `defer` 确保释放

```
let p: *I8 = unsafe malloc(10)
defer unsafe free(p)
let v = unsafe 加载(p)
```

### 9.6 安全封装模式 `[Experimental]`

**原则**：不安全内核写成 `|unsafe` 自由函数，安全方法 / 函数检查所有前置条件后，通过 `unsafe` 消耗点调用不安全自由函数。

**示例**：

```
[libc|foreign]
malloc|unsafe(大小: I64,) -> *I8
free|unsafe(指针: *I8,) -> ()

写入原始|unsafe(目标: *I8, 偏移: I64, 数据: [I32],) -> ():
    for (值, 索引) in 数据:
        存储(目标 + 偏移 + 索引, 值)
    return

{缓冲区}
_指针: *I8 = nil
_容量: I64 = 0

写入|self(偏移: I64, 数据: [I32],) -> ^():
    if 偏移 < 0 || 偏移 + len(数据) > self._容量:
        return .err("越界")
    unsafe 写入原始(self._指针, 偏移, 数据)
    return .ok(())
```

**结构**：

| 层 | 角色 |
|---|---|
| `[libc\|foreign]` | 声明外部 C 函数 |
| `\|unsafe` 自由函数 | 不安全内核，显式获得全部输入 |
| 安全方法 | 检查前置条件，调用不安全内核 |

**闭包不继承不安全上下文**：

```
写入内存|unsafe(目标: *I8, 数据: [I32],) -> ():
    let 回调 = func (索引: I32,) -> ():
        unsafe 存储(目标 + 索引, 数据[索引])
        return
    return
```

即使定义在 `|unsafe` 函数内部，闭包体也是安全的，需要 `unsafe` 消耗点。

**已知限制（Experimental 显式登记）**：

| 限制 | 说明 |
|---|---|
| 解释器 `&` 快照取址 | 写回不更新原变量 |
| LLVM 端 FFI | 显式 unsupported |
| by-value 结构体 ABI | Phase 2c 范围 |
| 变参函数 | 不支持 |
| 回调 / 函数指针参数 | 不支持 |
| `errno` / 线程局部访问 | 不支持 |
| 非 C 的 ABI | 不支持 |

## 第 10 章 模块系统

### 10.1 pini.toml `[Provisional]`

模块清单文件。

**基本结构**：

```toml
[package]
名称 = "我的项目"
版本 = "0.1.0"

[require]
库A = "1.0"
库B = "2.0"

[require.私有源]
库C = "1.0"

[tap]
私有源 = "github:org/repo"

[resources]
数据 = "path/to/data"

[replace]
库A = "1.5"

[ffi]
abi = "C"
libs = ["m", "pthread"]

[[bin]]
名称 = "主程序"
entry = "src/main.pini"

[lib]
entry = "src/lib.pini"

[build]
exclude = ["tests/fixtures"]
```

**节说明**：

| 节 | 用途 |
|---|---|
| `[package]` | 模块名、版本 |
| `[require]` | Pini 模块依赖（根有 `pini.toml`） |
| `[require.<tap>]` | 私有源依赖 |
| `[resources]` | 非 Pini 资源（根无 `pini.toml`） |
| `[resources.<tap>]` | 私有源资源 |
| `[tap]` | 声明依赖从哪来 |
| `[replace]` | 强制版本 / 本地 / 换 fork |
| `[ffi]` | FFI 配置 |
| `[[bin]]` | 可执行入口 |
| `[lib]` | 库入口 |
| `[build]` | 构建配置 |

**已移除**：`[dependencies]`（职责拆分给 `require` + `resources`）。

**判据**：目标根有无 `pini.toml`。

| 通道 | 目标根有 `pini.toml` | 可 import | MVS |
|---|---|---|---|
| `[require]` | 是 | 是 | 是 |
| `[resources]` | 否 | 否 | 否 |

**双向强制**：把资源写进 `require`、或把模块写进 `resources`，均报错并指引到另一侧。

**`[replace]` 三种形态**：

```toml
[replace]
库A = "1.5"                          ; 只换版本
库B = "file:../本地目录"              ; 换本地目录
库C = "github:org/fork@2.0"          ; 换 fork
```

仅主模块生效。

### 10.2 依赖解析 `[Provisional]`

**MVS（最小版本选择）**：

- 输入：`[require]` 的传递闭包
- 结果生成到 `pini-summary.toml`（生成物但**必须提交**）
- 候选来自 tag
- 取满足全部约束的最小版本
- 有界不动点迭代（上限 8 轮，不收敛即报错）

**锁文件 `pini-summary.toml`**：

- 记录每依赖的可用版本
- 记录 `commit`（真实来源定位符）
- 记录 `tap` / `source`（来源）
- SHA-256 校验和（TOFU）

**命令**：

| 命令 | 行为 |
|---|---|
| `pini mod tidy` | 离线对齐集合 |
| `pini mod refresh` | 重解版本并下载（唯一联网） |
| `pini mod verify` | 执行校验和 |
| `pini mod graph --cycles` | 输出依赖环 |

**约束**：

- 无全局缓存
- 无 clean
- build 永不抓取

### 10.3 文件命名 `[Provisional]`

| 文件 | 用途 |
|---|---|
| `pini.toml` | 模块清单 |
| `pini-summary.toml` | 锁文件 |

**命名规则**：

- 文件名是 R1 判定模块边界的哨兵
- 须特异到误判率近零
- 旧名 `module.toml` 命中即报错，不得静默降级

**`_` 前缀文件**：

- 文件名以 `_` 开头 → 文件内符号为 internal（当前文件可见）

### 10.4 目录命名 `[Provisional]`

| 目录 | 用途 |
|---|---|
| `.pini/` | 工具命名空间根 |
| `deps/` | 依赖模块 |
| `_` 前缀 | package 级可见性 |

**`.pini/` 结构**：

```
.pini/
  ├─ resources/<name>/    ; 资源
  ├─ toolchain/<name>/    ; 宿主工具链
  ├─ build/               ; 产物
  ├─ cache/               ; 缓存
  └─ baseline             ; 宿主标定记录（ADR-024 D8）
```

**规则**：

- 点前缀目录（`.` 开头）不参与任何模块的源码扫描
- 只取 `.`，不取 `_`（`_` 在 Pini 是 package 级可见性语义）
- 项目宿主放 `.pini/toolchain/`，不属 `resources`

**模块边界（R1）**：

- 以 `pini.toml` 划分模块
- 目录树排除含 `pini.toml` 的子目录（嵌套即词法包含）
- `deps/` 只放 `require` 的模块（各自带清单，R1 自切）

### 10.5 跨模块访问 `[Provisional]`

**依赖图**：

- `import` 即依赖
- `import` 是文件级声明
- 模块依赖 = 该模块所有文件 import 的并集
- 依赖图无环（构建时 SCC 检测）
- 成环报错并给出环路径（如 `app → text → uni → app`）
- 环检测通过 ⇒ DAG ⇒ 拓扑序编译，顶层初始化顺序良定义

**禁环的代价**：

- 父子模块不能互相使用
- 需要互相引用时必须抽出第三方模块（依赖倒置）

**全导入**：

```
[文件名|import]
别名 = "模块路径"
_隐式 = "模块路径"
```

| 形式 | 访问方式 |
|---|---|
| `别名 = "路径"` | `别名.符号` 限定访问 |
| `_隐式 = "路径"` | 裸调用 + `_别名.符号` 限定调用 |

**别名规则**：

- 模块内非 `_` 别名到模块的绑定必须全局一致
- `_别名` 为文件私有导入，不进模块共享表面
- 别名静态消解，不占运行时值命名空间
- 别名不必等于目标模块名（不一致仅发 E7-002 弱警告）

**注入导入（D-4）**：

- `_别名 = path` = 目标模块 public 符号进入**本文件**裸名空间
- 可裸调用或以 `_别名.符号` 限定调用
- 非 `_` 别名必须限定调用（两通道不混）
- 注入符号与本文件任何可裸引用名相撞 → E3-013 歧义错误
- v1 边界：注入不跨模块传递；单文件 run 无语义检查

**访问门槛**：

| 级别 | 可被跨模块引入 |
|---|---|
| private | ❌ |
| internal | ❌ |
| package | ❌ |
| public | ✅ |

跨模块引入门槛 = 仅 `public`。

**`package` 级释义收窄**：

- 本模块及其后代子模块可见
- 不可被跨模块引入

**`public` 级释义**：

- 同模块可见
- 可被引入

**`private` 与 `internal`**：

- 可达范围上保持同桶（均为「仅本文件可达」）
- 封装性由文件内保证
- 差异在作用域是符号级还是文件级，不在可达范围

**import / export 块形式**：

| 块 | 用途 |
|---|---|
| `[名称\|import]` | 依赖声明 |
| `[名称\|export]` | 导出控制 |

块头名 = 当前文件名（去 `.pini` 后缀），解析器校验一致。

**示例**：

```
; 文件 app.pini
[app|import]
工具 = "utils/text"
_数学 = "utils/math"

工具.处理()          ; 限定调用
处理()               ; 裸调用，_数学 注入导入
_数学.计算()         ; 也可限定调用
```

## 第 11 章 错误模型

### 11.1 Result 类型 `[Provisional]`

**类型语法糖**：

```
^T     ≡ Result<T, E>
```

**构造**：

```
let r: ^I32 = .ok(42)
let e: ^I32 = .err(Error())
```

**语义**：

| 用例 | 含义 |
|---|---|
| `.ok(值)` | 成功，携带值 |
| `.err(错)` | 失败，携带错误 |

**函数返回 Result**：

返回位文法只接受元组，因此函数返回 `Result` 的官方写法是把 `^T` 类型糖嵌为返回元组字段：

```
读取文件(路径: String,) -> (^String,):
    return .err(Error())
```

- `-> (^T,)` 中 `^T` 展开呈现为 `Result<T>`
- 单字段返回元组 ≡ 返回一个 `Result` 值
- 调用方拿到该字段后以 try-else / `^e` 消费
- `-> Result(T,)` 直写形态不合法

**带形参的裸声明**：不带返回标注无法消歧，返回 `Result` 的函数必须显式写 `-> (^T,)`。

### 11.2 try-else `[Provisional]`

**唯一原语 try-else**：

```
try 表达式 else 错误绑定名: 控制流语句
try 表达式 else 错误绑定名:
    控制流语句块
```

**操作数**：静态要求 `Result<T, E>`（类型层拦截，非 Result → E4 类型错）。

**成功路径**：`ok(v)` → 解包值 `v`。

**失败路径**：`err(e)` → 错误值 `e` 绑定到错误绑定名，执行控制流语句。

**错误始终是值**，不在调用栈上抛异常（errors-as-data）。

**语句位与表达式位同形**：

| 位置 | 形式 | 结果 |
|---|---|---|
| 语句位 | `try f() else err: return err` | 丢弃成功值 |
| 表达式位 | `let x = try f() else err: return err` | 值 = 成功路径解包值 |

**单行 handler**：仅限控制流语句（`return` / `break` / `continue`）与 `pass`。

- `pass` 仅语句位合法（「显式吞掉错误」惯用法）
- 表达式位无值故拒绝

**块形式**：须以控制流语句终止（静态校验）。

**示例**：

```
读取配置(路径: String,) -> (^配置,):
    let 内容 = try 读取文件(路径) else err: return err
    let 配置 = try 解析(内容) else err: return err
    return .ok(配置)
```

**`^` 右值糖重定义为脱糖**：

```
^e     ≡ try e else err: return err
```

定义性脱糖——规范语义以 try-else 表达式位给出。

**三重身份消歧**：

| 记号 | 位置 | 含义 |
|---|---|---|
| `^T` | 类型位 | 结果类型糖 |
| `^e` | 表达式位前缀 | 右值解包糖 |
| `a ^ b` | 中缀 | 位异或 |
| `^=` | 复合赋值 | 按位异或赋值 |

**函数返回 Result 的标注写法**：

```
读取文件(路径: String,) -> (^String,):
    return .err("模拟错误")
```

调用方：

```
main() -> ():
    let 内容 = try 读取文件("配置.txt") else err:
        print("读取失败")
        return
    print(内容)
    return
```

**与异步错误的关系**：

`await` / `wait` join 得到的 `Future` 求值为 `Result`，其 `CancelError` 落在 `err` 用例中，经 try-else 正常捕获、不穿透。

`CancelError` 不绕过 errors-as-data 模型。

**已知限制（Provisional 显式登记）**：

| 限制 | 说明 |
|---|---|
| 单错误绑定名 | 不按错误类型分派 |
| 类型化多分支捕获 | 后续增强 |
| 嵌套 try-else 作用域 | 随迁移批钉定 |
| 错误绑定名遮蔽规则 | 同上 |

### 11.3 错误即数据 `[Stable]`

**核心原则**：错误是值，不在调用栈上抛异常。

**与异常模型的对比**：

| 维度 | 异常模型 | 错误即数据 |
|---|---|---|
| 控制流 | 隐式跳转 | 显式 match |
| 类型 | 异常类型层次 | `Result<T, E>` |
| 编译器支持 | 异常表 / 栈展开 | 无特殊指令 |
| 可预测性 | 低 | 高 |
| 性能 | 抛出时开销大 | 无特殊开销 |

**Pini 的选择**：

- `Result<T, E>` 是普通标签联合
- `try` 是 match 语法糖
- 字节码不需要特殊指令
- 全用已有指令（`NEWENUM`、`MATCHTAG`、`JMPIF`、`GETTUPLE`）

**内建错误类型**：

| 类型 | 用途 |
|---|---|
| `Error()` | 通用错误 |
| `CancelError()` | 取消错误 |
| `Result` | 结果类型 |

**构造**：

```
return .err(Error())
return .err(CancelError())
```

**错误传播模式**：

```
函数A() -> (^I32,):
    let x = try 函数B() else err: return err
    let y = try 函数C() else err: return err
    return .ok(x + y)
```

每一步显式传播，无隐式跳转。

**与并发的关系**：

- `await` / `wait` join 结果经 try-else 解构
- `CancelError` 正常捕获
- 失败上浮在函数返回边界（见 §8.4）

## 第 12 章 运行时与执行

### 12.1 执行概览 `[Provisional]`

Pini 的执行路径：

```
源码
  → 词法 → 语法 → AST
  → 语义分析 → HIR（结构化 SSA，唯一分析 IR）
  → 解释器 / LLVM IR / 字节码 / C
  → 执行
```

**当前实现状态**：

| 路径 | 状态 |
|---|---|
| 解释器（AST） | ✅ 已实现 |
| 解释器（HIR） | ✅ 已实现 |
| LLVM IR | ✅ 已实现 |
| 字节码 | ◐ 设计完成，未落地 |
| C 后端 | ◐ 设计完成，未落地 |
| WASM | ◐ 设计完成，未落地 |

**HIR 作为单一分析 IR**：

- 所有分析（SCC、逃逸、ARC 插入、COW）在 HIR 上完成
- 各后端消费 HIR，各自降级
- 解释器双引擎（AST + HIR）用于语义交叉验证

### 12.2 解释器 `[Provisional]`

**双引擎**：

| 引擎 | 输入 | 用途 |
|---|---|---|
| AST 解释器 | AST | 参考实现，语义基准 |
| HIR 执行器 | HIR | 与编译路径对齐 |

**语义交叉验证**：两条路径逐字节比对输出，确保语义一致。

**挂起/恢复模型**：

- CPS 求值器支持任意表达式深度挂起
- 已执行副作用不重跑
- 上下文五项还原：`{currentEnv, currentFuture, deferStack, debugDepth, callStackNames}`
- 跨线程恢复（work-stealing 复用 OS 线程）

**调度后端**：

| 后端 | 用途 |
|---|---|
| `GCDScheduler` | 默认阻塞后端 |
| `SuspendScheduler` | 挂起模式，work-stealing 池 |

**运行时入口**：

| 入口 | 用途 |
|---|---|
| `Interpreter.run` | 执行程序 |
| `Interpreter.runTests` | 执行测试 |
| `main` 函数 | 程序入口 |

**测试入口四项**：

| 规则 | 说明 |
|---|---|
| 不直接暴露给用户 | 由工具对 `\|test` 的处理交付 |
| 执行顺序不保证 | 测试之间不得有顺序依赖 |
| 收集粒度三形态 | 默认模块根 / 显式路径 / 单文件 |
| 与 main 互斥 | `pini test` 不执行 main，`pini run` 不执行测试 |

### 12.3 LLVM 后端 `[Provisional]`

**管线**：

```
HIR → LLVM IR → LLVM 工具链 → 目标二进制
```

**类型映射**：

| HIR | LLVM |
|---|---|
| 标量 | 原生标量 |
| struct | 结构体 |
| object | 指针 + 对象头 |
| enum | 标签 + 载荷 |
| 数组 | 运行时句柄 |
| 字符串 | 运行时句柄 |

**运行时调用**：

IR 经 `call @bk_*` 调用运行时 shim。

**已知限制**：

| 限制 | 说明 |
|---|---|
| FFI | 显式 unsupported |
| 部分内建 | `.get` / `.getUnchecked` 未实现 |
| 跨模块 | IR 后端不支持（后续批次） |
| 挂起模式 | 部分形态 unsupported |

**语义一致性**：与解释器逐字节一致，由 `RuntimeBackendTests` 三执行路径锁步验证。

### 12.4 运行时 shim `[Provisional]`

**`libPiniRuntime`**：Swift 实现的 shim 库，`.dynamic` target。

**加载方式**：

- `lli --dlopen`
- `clang -L/-l`

**C-ABI 面**：

| 前缀 | 用途 |
|---|---|
| `bk_array_*` | 数组操作 |
| `bk_dict_*` | 字典操作 |
| `bk_set_*` | 集合操作 |
| `bk_lazyref_*` | 懒加载 |
| `bk_panic` | panic |
| `bk_handle_*` | share 管理 |
| `bk_ptr_*` | 指针原语 |
| `bk_double_to_string` | 浮点展示 |

**硬性约束（MUST）**：

shim 与用户代码的边界必须是 C ABI，不是 Swift 泛型 ABI。

- 违反即锁死自举终态
- 使 Swift 成为永久依赖
- 已实证可守住不泄漏 Swift 类型

**不透明句柄**：

- IR `ptr` 承载
- 类型检查 / 推断层只见 opaque handle
- `IRBuilder` 对集合与 LazyRef 一律建模为 opaque C-ABI handle

**统一 shim 边界**：

集合、并发、LazyRef、FFI 共用单一 `libPiniRuntime` C-ABI 面，不另设独立 shim。

**长期愿景**：

| 阶段 | 内容 | 触发条件 |
|---|---|---|
| 1 | Swift shim（当前） | — |
| 2 | C-ABI 版本化固化 | 出现真实第二后端 |
| 3 | 自举纯 libc | Pini 成熟后 |

**回滚**：若阶段 1 实测内部不变量无法守住，可回退到纯 LLVM 手写 IR。

### 12.5 执行语义 `[Provisional]`

#### 值语义

| 类型 | 复制行为 |
|---|---|
| 标量 | 值复制 |
| struct | 字段槽位值拷贝 |
| 元组 | 元素值拷贝 |
| 数组 / 字典 / 集合 | COW |
| enum | 值复制 |

#### 引用语义

| 类型 | 复制行为 |
|---|---|
| object | 引用复制，计数 +1 |
| `WeakRef<T>` | 引用复制，共享 box |
| `LazyRef<T>` | 引用复制，共享 box |
| `UnownedRef<T>` | 裸指针复制 |

#### ARC 执行

- 引用复制 → `RETAIN`
- 引用丢弃 → `RELEASE`
- 计数归零 → `deinit` + 清空弱引用 + 释放内存
- 延迟释放队列避免析构风暴

#### COW 执行

- 复制 → 共享存储，存储计数 +1
- 只读 → 无复制
- 写入且唯一 → 原地修改
- 写入且共享 → 克隆存储

#### 并发执行

- 任务树：父强持有子，子弱引用父
- `await`：挂起，保存续体，释放线程
- `wait`：阻塞等待
- `detach`：脱离任务树
- 取消：协作式，在挂起 / resume 边界生效
- 错误：经 `Result` 显式传播

#### 浮点展示

**最短往返表示**（与 Swift `Double.description` 一致）：

| 规则 | 说明 |
|---|---|
| 往返恒等 | 展示串解析回 F64 后逐位相等 |
| 定点/指数切换 | `[1e-4, 1e16)` 定点，越界指数 |
| 定点恒带小数点 | `1000000.0` |
| 指数形态 | `e±NN` 两位指数 |

**一致性**：解释器通道与 LLVM 通道必须逐字节一致，HIR 差分套件以边界值 fixture 锁定。

## 第 13 章 形式文法

### 13.1 词法文法 `[Provisional]`

#### 记号约定

```
::=          定义
|            备选
[ ... ]      可选（0 或 1 次）
{ ... }      重复（0 或多次）
( ... )      分组
'x'          终结符字面量
IDENT INT    词法类
(* ... *)    注释
<snake_case> 非终结符
```

语言自身用 `( ) [ ] { } < > |` 作为定界符/运算符，故 EBNF 中所有语言符号一律加引号。

#### 词法类

```
IDENT        ::= ID_START ID_CONTINUE*
               | '`' ESCAPED_NAME '`';
ID_START     ::= [\p{L}_];
ID_CONTINUE  ::= ID_START | NUMERIC;
NUMERIC      ::= (* Unicode numeric property 字符 *)
```

反引号转义：整体产出 IDENT token、跳过关键字分类，允许关键字作标识符/构造标签。未闭合或空内容回退宽松词法兜底。

宽松词法：未被上述词法类匹配的字符产出单字符 IDENT token（文本 = 该字符）；词法器对任何输入不报错——非法性诊断由解析/语义阶段给出。

#### 关键字

```
KEYWORD      ::= 'var' | 'let' | 'func' | 'enum' | 'object'
               | 'if' | 'elif' | 'else' | 'match' | 'case'
               | 'while' | 'step' | 'for' | 'in'
               | 'try' | 'return' | 'break' | 'continue'
               | 'self' | 'own' | 'defer' | 'import' | 'export'
               | 'nil' | 'capture' | 'await' | 'wait'
               | 'unsafe' | 'test' | 'foreign' | 'detach'
               | 'scope' | 'pass';
```

共 34 个。

#### 字面量

```
INT          ::= [0-9]+ | '0x' [0-9a-fA-F]+ | '0b' [01]+ | '0o' [0-7]+;
FLOAT        ::= [0-9]+ '.' [0-9]+ [EXP]? | [0-9]+ EXP;
EXP          ::= ('e'|'E') ['+'|'-'] [0-9]+;
STRING       ::= '"' { STRING_CHAR | ESCAPE } '"';
STRING_CHAR  ::= (* 除 '"' 与换行外的任意字符 *);
ESCAPE       ::= '\' ('n'|'t'|'r'|'0'|'\\'|'"'|'(');
INTERP       ::= '"' { STRING_CHAR | ESCAPE | '\(' INTERP_EXPR ')' } '"';
INTERP_EXPR  ::= (* 平衡括号表达式源码；可含嵌套 ()[]{} 与字符串；
                    不支持嵌套 '\\(' *);
BOOL         ::= 'true' | 'false';
```

```
OPERATOR ::= '+' | '-' | '*' | '/' | '%'
           | '++' | '--'

           | '==' | '!=' | '<=' | '>=' | '<' | '>'
           | '&' | '|' | '^' | '~' | '<<' | '>>'
           | '='
           | '+=' | '-=' | '*=' | '/=' | '%='
           | '&=' | '|=' | '^=' | '<<=' | '>>=';

DELIMITER ::= '(' | ')' | '[' | ']' | '{' | '}' | ':' | ',' | '->' | '=>' | '.'
            | '|' | '?' | '*' | '@';

NEWLINE   ::= (* 行尾换行，每行行尾产出 1 个 NEWLINE *);
INDENT    ::= (* 行首缩进大于栈顶 → push + INDENT *);
DEDENT    ::= (* 行首缩进小于栈顶 → 逐层 pop + DEDENT *);
EOF       ::= (* 文件结束 *);
```

```
COMMENT ::= ';' { (* 除换行外任意字符 *) }
          | '#' { (* 除换行外任意字符 *) };
```

### 13.2 语法文法 `[Provisional]`

#### 模块与顶级结构

```
module          ::= { NEWLINE } { top-level-decl NEWLINE } EOF;

top-level-decl  ::= import-decl | export-decl
                  | struct-decl | object-decl | object-decl-sugar | enum-decl
                  | bare-func-decl | trait-decl | extension-decl | foreign-decl;

import-decl     ::= '[' IDENT '|' 'import' ']' NEWLINE { import-item };

export-decl     ::= '[' IDENT '|' 'export' ']' NEWLINE { export-item };
export-item     ::= IDENT '=' IDENT
                  | IDENT ':' type-annotation;
```

#### 类型声明

```
struct-decl     ::= '(' IDENT ['<' generic-params '>'] ')' NEWLINE struct-body;

object-decl     ::= '[' IDENT ['<' generic-params '>'] ['|' 'object'] ']' type-body;
enum-decl       ::= '[' IDENT ['<' generic-params '>'] ['|' 'enum'] ']' enum-body;

object-decl-sugar ::= '{' IDENT '}' type-body;

trait-decl      ::= '<' IDENT '>' trait-body;

trait-body      ::= { trait-method };
trait-method    ::= IDENT ['|' ('self' | 'own')] func-signature [func-body];

extension-decl  ::= '((' IDENT ['<' generic-params '>'] [':' type-annotation] '))' method-body
                  | '{{' IDENT ['<' generic-params '>'] [':' type-annotation] '}}' method-body
                  | '[[' IDENT ['<' generic-params '>'] [':' type-annotation] ']]' method-body
                  | '<<' IDENT '>>' trait-body;

foreign-decl    ::= '[' IDENT '|' 'foreign' ']' foreign-body;

struct-body     ::= [composition-line] { field-decl };
type-body       ::= { field-decl };
enum-body       ::= { enum-case };
method-body     ::= { method-decl };
foreign-body    ::= { foreign-signature };

composition-line ::= IDENT;

field-decl      ::= IDENT ':' type-annotation ['=' expression];

enum-case       ::= IDENT ['(' type-annotation {',' type-annotation} [','] ')'];

method-decl     ::= IDENT ['|' 'self' | '|' 'own'] func-signature [func-body];

foreign-signature ::= IDENT func-signature;
```

#### 函数声明

```
func-signature  ::= ['<' generic-params '>'] '(' [param {',' param} [',']] ')'
                    [('->' | '=>') '(' [ret-item {',' ret-item} [',']] ')']
                    [':' func-body];

param           ::= IDENT [':' type-annotation]
                  | IDENT '=' expression;

ret-item        ::= [IDENT ':'] type-annotation;

modifier        ::= 'func' | 'self' | 'own' | 'test' | 'unsafe' | 'foreign';

bare-func-decl  ::= IDENT ['|' modifier] ['<' generic-params '>'] func-signature;

func-literal    ::= 'func' '(' [param {',' param} [',']] ')'
                    [('->' | '=>') '(' [ret-item {',' ret-item} [',']] ')'] ':' func-body;

capture-stmt    ::= 'capture' IDENT ;

func-body       ::= INDENT { statement } DEDENT;
```

#### 语句

```
statement       ::= var-decl | assign-stmt | return-stmt | break-stmt | continue-stmt
                  | if-stmt | while-stmt | for-stmt | match-stmt | try-stmt
                  | defer-stmt | pass-stmt | expression-stmt
                  | detach-expr-stmt | capture-stmt;

var-decl        ::= ('var' | 'let') IDENT [':' type-annotation] ['=' expression]
                  | ('var' | 'let') '(' pattern-tuple ')' [':' type-annotation] '=' expression;

assign-stmt     ::= assign-target assign-op expression;
assign-target   ::= IDENT | postfix-expression '.' IDENT | postfix-expression '[' expression ']';
assign-op       ::= '=' | '+=' | '-=' | '*=' | '/=' | '%=' | '&=' | '|=' | '^=' | '<<=' | '>>=';

return-stmt     ::= 'return' [expression];
break-stmt      ::= 'break' [IDENT];
continue-stmt   ::= 'continue' [IDENT];

if-stmt         ::= [IDENT '|'] 'if' expression control-block
                    { 'elif' expression control-block }
                    [ 'else' control-block ];

while-stmt      ::= [IDENT '|'] 'while' expression control-block ['step' control-block];
for-stmt        ::= [IDENT '|'] 'for' '(' pattern-tuple ')' 'in' expression control-block
                    ['step' control-block];

pattern-tuple   ::= (IDENT | '_') { ',' (IDENT | '_') } [ ',' ];

match-stmt      ::= 'match' expression ':' { match-case };
match-case      ::= 'case' match-pattern control-block;
match-pattern   ::= '_' | INT | FLOAT | STRING | BOOL | IDENT | 'nil';

try-stmt        ::= try-expr;
try-expr        ::= 'try' expression 'else' IDENT try-handler;
try-handler     ::= ':' (return-stmt | break-stmt | continue-stmt | pass-stmt)
                  | ':' INDENT { statement } DEDENT;

defer-stmt      ::= 'defer' (assign-stmt | expression-stmt)
                  | 'defer' ':' func-body;

pass-stmt       ::= 'pass';
expression-stmt ::= expression;
detach-expr-stmt ::= 'detach' expression;

control-block   ::= ':' (expression | INDENT { statement } DEDENT);
```

#### 表达式

```
expression      ::= or-expr;

or-expr         ::= and-expr { '||' and-expr };
and-expr        ::= equality-expr { '&&' equality-expr };
equality-expr   ::= comparison-expr { ('==' | '!=') comparison-expr };
comparison-expr ::= bitwise-expr { ('<' | '>' | '<=' | '>=') bitwise-expr };
bitwise-expr    ::= term { ('&' | '|' | '^' | '<<' | '>>') term };
term            ::= factor { ('+' | '-') factor };
factor          ::= unary-expr { ('*' | '/' | '%') unary-expr };

unary-expr      ::= ('await' | 'wait' | '^' | '!' | '++' | '--' | '~' | '+' | '-' | '&' | 'unsafe') unary-expr
                  | primary-expr;

primary-expr    ::= primary-atom postfix-suffix*
                  | try-expr;

postfix-suffix  ::= '(' [call-arg {',' call-arg} [',']] ')'
                  | '.' IDENT
                  | '[' subscript ']'
                  | '!';

subscript       ::= index | slice;
index           ::= expression;
slice           ::= [expression] ':' [expression];

call-arg        ::= [IDENT '='] expression;

primary-atom    ::= IDENT [generic-construct]
                  | 'self' | 'own'
                  | func-literal
                  | INT | FLOAT | STRING | INTERP | BOOL
                  | 'nil'
                  | '(' [tuple-element {',' tuple-element} [',']] ')'
                  | '[' collection-literal ']'
                  | '{' [expression {',' expression} [',']] '}'
                  | '.' IDENT
                  | builtin-call;

tuple-element   ::= [IDENT '='] expression;

generic-construct ::= '<' type-annotation {',' type-annotation} '>'
                      ('(' [call-arg {',' call-arg} [',']] ')' | '.');

collection-literal ::= ']'
                     | expression '=' expression {',' expression '=' expression} [','] ']'
                     | expression {',' expression} [','] ']';

builtin-call    ::= 'LazyRef' ['<' type-annotation '>'] '(' func-literal ')'
                  | 'assert' '(' expression [',' STRING] ')';
```

#### 类型注解

```
type-annotation ::= '?' type-annotation
                  | '^' type-annotation
                  | '*' type-annotation
                  | '[' type-annotation ']'
                  | '[' type-annotation ':' type-annotation ']'
                  | '{' type-annotation '}'
                  | IDENT ['<' type-annotation {',' type-annotation} '>']
                  | '(' [type-annotation {',' type-annotation} [',']] ')'
                    [('->' | '=>') '(' [type-annotation {',' type-annotation} [',']] ')']
                  | 'self' | 'own';

generic-params  ::= IDENT [':' type-annotation] {',' IDENT [':' type-annotation]};
```

### 13.3 运算符优先级 `[Provisional]`

| 层级（低→高） | 运算符 | 结合性 |
|---|---|---|
| 1 | `\|\|` | 左 |
| 2 | `&&` | 左 |
| 3 | `==` `!=` | 左 |
| 4 | `<` `>` `<=` `>=` | 左 |
| 5 | `&` `\|` `^` `<<` `>>` | 左（同级） |
| 6 | `+` `-` | 左 |
| 7 | `*` `/` `%` | 左 |
| 8 | 前缀 `await` `wait` `^` `!` `++` `--` `~` `+` `-` `&` `unsafe` | — |
| 9 | 后缀 `()` `.` `[]` `!` | — |

**注意**：位运算四项同级（`&` `|` `^` `<<` `>>` 无分层），与 C 系不同。

### 13.4 记号消歧规则 `[Provisional]`

| # | 规则 | 说明 |
|---|------|------|
| 3.0 | 行首定界符分派 | `(` `[` `{` `<` 在行首 → 顶级类型声明分派；非行首 → 字面量/元组/泛型/优先结合 |
| 3.1 | `await`/`wait` 前缀 join | 关键字、仅作表达式起始位前缀 → 映射 `.join` AST；`<=` 已回归纯比较运算符 |
| 3.2 | 类型体内禁止函数声明 | 类型体内只允许字段声明；遇函数声明头 → 报错提示移至扩展块 |
| 3.3 | `<` 泛型构造 vs 比较 | `IDENT '<' type {',' type} '>'` 且 `>` 后跟 `(`/`.` 才判定 generic-construct |
| 3.4 | `{名称}(...)` 花括号函数已移除 | 行首 `{名称}` 恒为对象声明糖；花括号函数形态报 E2-005 |
| 3.5 | `[名称\|...]` 枚举 vs 对象 | `\|object` → 对象；`\|enum` → 枚举；无修饰符默认枚举 |
| 3.6 | 裸函数声明判定 | `IDENT ('\|mod')? '<泛型>'? '(' 参数 ')'` 后跟 `->`/`=>` → 裸函数声明 |
| 3.7 | match `default` 消歧 | `default` 是普通标识符；match 子块内 `default:` 显式报错提示改 `case _:` |
| 3.8 | 泛型构造 lookahead 失败回退 | 任一环节不满足 → 恢复 position 回退为比较运算 |
| 3.9 | 内嵌组合 | `(类型)` 后首行裸父类型名、非字段/裸函数 → 内嵌父类型 |
| 3.10 | match 子块结构 | match 子块内只允许 `case`；`case _:` 为通配兜底 |
| 3.11 | 复合赋值折叠 | `x op= y` 语法上是 assign；语义 = `x = (x op y)` |
| 3.12 | `nil` 映射 | 表达式/匹配模式中 `nil` ≡ `Optional.none` |
| 3.13 | 标签语法消歧 | 语句位置 `IDENT '\|'` 后跟控制流关键字 → 标签；声明位置后跟修饰符 → 声明修饰 |
| 3.14 | 扩展块内禁止自由函数 | 扩展块内只允许带 `\|self` 或 `\|own` 的方法声明 |
| 3.15 | 枚举关联参数 | 具名 `IDENT ':' type` 或位置 `type`；构造实参用 `IDENT '=' expression` |
| 3.16 | 下标 vs 切片消歧 | `[` 内首个非空白 token：`:` → 切片；否则先解析 expression，后跟 `:` → 切片 |
| 3.17 | 切片开放边界语义 | 省略边界脱糖为 `nil`；半开区间 `[i, j)`；负索引尾部计数 |

**规则 3.13 与 3.14 的上下文区分**：

| 上下文 | `IDENT '\|'` 后跟 | 解释 |
|---|---|---|
| 语句上下文 | 控制流关键字 | 标签 |
| 语句上下文 | 其他 | 按位或表达式 |
| 声明上下文 | 修饰符关键字 | 声明修饰 |
| 声明上下文 | 其他 | 裸函数声明的一部分 |

**规则 3.2 与 3.14 的协同**：

| 位置 | 行为 |
|---|---|
| 类型体内 | 函数声明 → 报错提示移至扩展块 |
| 扩展块内 | 自由函数 → 报错提示移至模块顶层 |
| 模块顶层 | 自由函数 → 合法；方法声明 → 报错提示移至扩展块 |
