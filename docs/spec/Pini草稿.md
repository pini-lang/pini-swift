# `核心语法`
- 参考ini语法，行敏感，缩进敏感，组合式编程
- 此语言语法顶级结构是，复合类型的单行标识符声明，和复合类型块的交替解释
- 关于行敏感，声明默认单行，块内按行分隔语句，遇到集合语法（如元组）允许多行
- 关于缩进敏感，复合类型的内容允许并默认顶格缩进，特殊地，函数（可执行块）的内容必须按层次缩进且至少缩进一层
- 不鼓励在顶级域内而鼓励在块内声明独立字面量
- 不鼓励独立的指针变量而鼓励复合的引用类型（即object）
- 不鼓励多重嵌套而鼓励平坦的编码风格，鼓励数据与逻辑分离
- 不支持元编程

## `;注释符`
- 注释由`;`开启，持续到行尾

## `#文档注释符`
- 文档注释由行首`#`开启，持续到行尾；可能退化为行注释

## `"\(字符串插值)"`
- 在字符串字面量中以 `\(表达式)` 嵌入求值结果
- 例如 `"值=\(x)"` 将 `x` 的求值结果插入字符串

## `函数块(形式参数元组,)->(返回元组,)`
- 函数块是特殊的、多块复合的开启块
- 未缺省的声明是`函数块|func(形式参数元组,)->(返回元组,)`
- 关于错误传播，错误在返回元组中显式传播
- 裸函数名开头 + 参数元组 + `->`/`=>` + 返回元组
- 在成员中的签名被写作`(形式参数元组,)->(返回元组,)`，是“一等公民”，形如`成员名:(形式参数元组,)->(返回元组,)`

### `函数块(形式参数元组,)->返回类型`
- 这是为单类型的返回元组开放的语法糖，符合惯例且可以大幅度提升书写体验

### `Result<结果类型>`
- `.ok(值)`
- `.err(错)`
- 类型语法糖：`^结果类型`
- 右值（解包或控制返回错误）语法糖：`^结果右值`

### `特殊标识符`


### `异步函数块(形式参数元组,)=>(返回元组,)`
- 异步函数块内是异步上下文，允许使用`await`关键字
- `=>`起到标记函数块为async函数，并将返回元组加糖为`Future<(返回元组,)>`的作用
- 调用点的`await`关键字起到派发结构化子async函数并标记潜在挂起点的作用
- async函数在同步上下文中调用即被派发
- `detach` 关键字用于显式派发一个脱离当前结构化任务树的非结构化异步任务；该任务立即启动，其取消与错误不再沿树自动传播，调用者须持有返回的 `Future` 句柄以显式管理等待、取消与错误收集。
- 同步上下文允许使用`wait`关键字，调用点的`wait`关键字起到消费async函数并标记阻塞点的作用
- 子async的取消等细节由内置Future管理

### `函数调用(形式参数元组,)`
- 位置参数是具类型但不具值的元组元素，且在声明和调用时集中前置
- 实际位置参数在调用时缺省是非法的
- 缺省参数是具值的元组元素，且在声明和调用时集中后置
- 暂时不支持实际缺省参数在调用时的乱序传入
### `变量中的匿名函数`
```
var 变量名 = func (形式参数元组,) -> (返回元组,): ; 采用类型推断
    return ; 此处省略内容
var 变量名 = func (形式参数元组,) => (返回元组,): ; 采用类型推断的async形式
    return ; 此处省略内容
var 变量名: (形式参数元组,)->(返回元组,) = func (形式参数元组,) -> (返回元组,): ; 免类型推断
    return ; 此处省略内容
var 变量名: (形式参数元组,)=>(返回元组,) = func (形式参数元组,) => (返回元组,): ; 免类型推断的async形式
    return ; 此处省略内容

变量名(实际参数元组,); 如函数般调用
let 变量名 = (func (形式参数元组,) -> (返回元组,):
    return ; 此处省略内容
)(实际参数元组,); 原地调用（IIFE）async形式同理
let v = wait 变量名(实际参数元组,); `wait` 显式等待并取得返回值
```
#### `capture 标识符`
- 匿名函数体内部列出需捕获的外部标识符，允许包括以`_`开头的标识符，多行列出，不支持表达式。

| 种类     | 对象捕获规则                    | 其他捕获规则 |
| ------ | ------------------------- | ------ |
| 普通函数   | 禁止捕获外部对象                  | 不限制    |
| 匿名函数   | 通过capture关键字捕获外部对象        | 不限制    |
| 测试函数   | 禁止捕获外部对象                  | 不限制    |
| 不安全函数  | 禁止捕获外部对象                  | 不限制    |
| （本身）方法 | 允许捕获self（及其成员），禁止捕获其他外部对象 | 不限制    |
| 本型方法   | 禁止捕获外部对象                  | 不限制    |

### `测试函数块必须显式声明|test(形式参数元组,)->(返回元组,)`
- 编译器收集所有测试函数并在入口依次调用。
### `不安全函数块必须显式声明|unsafe(形式参数元组,)->(返回元组,)`
- 不安全函数区别其他函数，启用不安全上下文。
- 调用不安全函数必须在 `unsafe` 消耗点后，或另一个不安全函数体内。
### `复合类型方法块必须显式声明|self(形式参数元组,)->(返回元组,)`
- 按照惯例，方法区别于函数，是被归属于复合类型的特殊函数概念
- 虽然归属于复合函数，但是声明在扩展块中，同文件扩展块内的方法可访问以`_`为前缀的字段
- 多个方法声明之间不可被其他的声明间隔，否则无法明确self归属的复合类型

## `FFI与unsafe`
- 关于FFI，在`pini.toml`中，模块级配置 `[ffi] abi = "C"` 可省略，默认为 C。
- 不引入文件级或块级 ABI 覆盖；混合 ABI 时应拆分模块处理。
- 复合类型中的指针字段不在数据层作限制；任何复合类型（普通 struct、object、元组）均可包含 `*T` 字段。
- 复制值类型时指针浅拷贝（与对象引用复制类似），持有安全，解引用需 `unsafe`。

### `unsafe 表达式`
- `unsafe` 是表达式前缀，标记单个不安全消耗点，精确控制最小不安全范围。
- `unsafe` 作用于紧随其后的单次函数调用或指针操作，复合表达式需用括号：`unsafe (加载(p) + 1)`。
- 任何函数体内均可使用 `unsafe` 消耗点：函数、方法、测试函数、闭包。

```
let 指针 = unsafe malloc(1024)
unsafe 存储(指针, 42)
let 值 = unsafe 加载(指针)
```

### `在不安全上下文中的C函数`
- `|unsafe` 仅限自由函数，表示“调用者必须保证某些前置条件”。
- 禁止与 `|self`、`|test` 组合，避免组合爆炸。
- `|unsafe`函数体自动处于不安全上下文，内部无需再使用 `unsafe` 前缀。

```
写入内存|unsafe(目标: *I8, 数据: [I32],) -> ()
    for (值, 索引) in 数据:
        存储(目标 + 索引, 值)
    return
```

### `*指针类型`
- `*T` 是指针类型语法糖，表示指向 `T` 的原始指针。
- `T` 必须是 C 兼容类型：标量、纯值类型结构体、或其他指针类型；禁止 `object` 或包含 `object` 字段的复合类型。
- 持有、传递、比较指针是安全的；解引用、指针算术、类型转换必须在 `unsafe` 消耗点后。
- 指针的初始化和释放由用户手动保证，语言不提供自动管理，建议使用 `defer` 确保释放。
- `&`前缀不安全取地址运算符

```
let p: *I8 = unsafe malloc(10)
defer:
    unsafe free(p)
let v = unsafe 加载(p)
```

### `[libc|foreign]`
- `foreign` 块声明外部 C 不安全函数签名。
- 调用规则与 `|unsafe` 函数一致：安全上下文中需要 `unsafe` 消耗点，`|unsafe` 函数体内可直接调用。
- 不接收内联 ABI 参数，继承模块级 `pini.toml` 中设定的 FFI ABI，默认为 `"C"`。

```
[libc|foreign]
malloc|unsafe(大小: I64) -> *I8
free|unsafe(指针: *I8) -> ()

安全分配|unsafe(大小: I64,) -> ^*I8:
    let 指针 = malloc(大小)
    if 指针 == nil:
        return .err("分配失败")
    return .ok(指针)
```

### `在不安全上下文中的匿名函数`
- 匿名函数不允许标记为 `|unsafe`。
- 闭包体内需要不安全操作时，使用 `unsafe` 消耗点。
- 闭包不继承外层函数的不安全上下文，即使定义在 `|unsafe` 函数内部，闭包体也是安全的。

```
写入内存|unsafe(目标: *I8, 数据: [I32],) -> ()
    let 回调 = func (索引: I32,) -> ():
        存储(目标 + 索引, 数据[索引])
        return
    return
```

### `与 ARC 的隔离`
- `*T` 指向的内存不是 ARC 对象，不参与自动引用计数。
- 编译器确保 `*T` 不能指向 ARC 对象，通过类型约束实现。
- 不允许将 ARC 对象转换为 `*T`，除非通过标准库的安全借用函数。

### `安全封装模式`
- 不安全内核写成 `|unsafe` 自由函数，通过参数显式获得全部输入。
- 安全方法/函数检查所有前置条件后，通过 `unsafe` 消耗点调用不安全自由函数。

```
写入原始|unsafe(目标: *I8, 偏移: I64, 数据: [I32],) -> ()
    for (值, 索引) in 数据:
        存储(目标 + 偏移 + 索引, 值)
    return

{缓冲区}
_指针: *I8
_容量: I64

写入|self(偏移: I64, 数据: [I32],) -> ^()
    if 偏移 < 0 || 偏移 + len(数据) > self._容量:
        return .err("越界")
    unsafe 写入原始(self._指针, 偏移, 数据)
    return .ok(())
```
