# ADR-004：原语层的 C ABI 形状

> **状态**：已接受（设计定稿；符号面已落地 —— 见「落地状态」）
> **决策日期**：2026-09-22（本件于 2026-09-23 自决策记录第二号的原语层半边拆出）
> **稳定性**：**不递交** —— 本件定的是**原语层**（实现与各后端之间）的契约，不属语言面构造
> **⭐ 编号规则**：**只增不改** —— 本编号不复用；**内容不受此限**（可后续修订）。
> **上级载体**：本仓语言规范的「语言级变更流程」与「运行时 shim 边界」条款。

---

## 1. 背景

「让出」要在语言层有载体，就必须先定**它落在哪条边界上**：语言侧说「让出」，
而「谁保存帧、谁恢复、怎么表示一个任务」是**宿主**的事。

⚠️ **一处论证上的绑定在此被拆开**：「**要可调度**」与「**必须轮询**」曾被当作同一件事。
二者其实**正交**——轮询与推送的差别只在**驱动层一层**，其余各层两路共用。
⇒ 结论：要可调度，**不必**轮询。本件定的是**共用的那几层**里的原语面形状。

---

## 2. 决策

### 2.1 三条既有硬约束（照抄，不新造第二套）

| # | 约束 |
|---|---|
| 1 | ⛔ **C ABI 是 MUST**：句柄 = `void*`，对外函数一律 `@_cdecl`。理由：否则纯 libc 重写阶段**被锁死** |
| 2 | **包装函数 ABI 已统一**：形如 `ptr (ptr code, ptr env, ptr out) -> ptr` —— 既有两处已在用 |
| 3 | **命名照既有族**：`bk_*`；长度 / 状态用 `i32`；返回值走 **out 缓冲**（规避返回栈地址的逃逸） |

### 2.2 符号面（并发面）

| 组 | 符号 | 语义 |
|---|---|---|
| 任务与 join（4） | `bk_task_spawn` | 派发任务体（**调用点就是派发点** ⇒ 实参即该次调用的实参） |
| | `bk_task_join` | **阻塞** join；out 写 `Result` 聚合 |
| | `bk_task_join_within` | 带超时阻塞 join；超时归约 `err`（`CancelError`） |
| | `bk_task_join_all` | 聚合，**fail-fast**：任一 `err` 即返回并取消其余 |
| 让出（4） | `bk_task_yield` | ⭐ **查询**语义：问后端**能否**让出。`1` = 能 · `0` = **合规降级**。⛔ 它**不执行**让出——执行让出的是**体的返回** |
| | `bk_task_await` | **可让出的等待**：`0` = 已决 ok · `1` = 已决 err / 已取消 · **`2` = 本次会让出**（`out` 未写） |
| | `bk_task_frame` | **帧的取用**：实例化一个体 ⇒ 建帧；体内取回当前任务的帧 |
| | `bk_task_slot` | **帧内取一个局部槽**：⭐ **可重放** —— 同一体第 n 次进入的第 k 次调用必得**同一地址** |
| 取消与结构（4） | `bk_task_cancel` · `bk_task_is_cancelled` · `bk_task_detach` · `bk_scope_close` | `bk_scope_close` ⛔ **留在原语层** —— 它的契约语义（泄漏子任务失败上浮）由**语言规范**定义，不由实现选择定义；放在原语层意味着**任何后端都必须实现它** |
| 能力与等待（2） | `bk_capabilities` · `bk_sleep` | 能力**分层 + 等级**（一层套一层，⛔ **不是矩阵**），承诺列**当前一律不给**；运行时解析 |

⚠️ **上表是「本决定所定」的符号面，不是原语层符号面的全集**：其后由「调度器表面」与
「调度驱动面」两批新增的符号（派发点的绑定口 · 任务的可观测态）不在此表，其形状由那两批的裁定承载。
⇒ ⛔ **本件不给「原语层共几个符号」这类计数** —— 那是会漂的数，它的主人是源码里那个 `@_cdecl` 面。

### 2.3 让出的形状（一处已订正的重要事实）

| 项 | 定案 |
|---|---|
| 让出是什么 | ⭐ **体返回「已让出」** —— 让出是**控制流的返回**，⛔ 不是一次调用 |
| 为什么 | 走「编译器可恢复帧」路线：与解释器侧的「帧栈 + 驱动器」**同形**；绕开本机宿主的栈切换缺口；无线程后端**今天只有这条路可走** |
| 续跑怎么做 | 运行时用**同一个**三元组（包装函数 · 代码 · 环境）**再调一次** ⇒ ⭐ **不需要第二个入口函数** |
| 环境参数的角色 | ⭐ 从「实参缓冲」升格为「**体的持久帧**」：派发点按体所需尺寸分配、体**只在真跑完时**释放；⛔ 让出时**不许**释放 |
| 帧的布局 | **发射层的私事**，⛔ 不成为 ABI 的一部分 |
| 返回码 `1` / `0` | 这一个位就是「本次让出是否真的会发生」的**可观测差异**。⛔ `0` **是合规降级，不是错误** |

---

## 3. 理由

**为什么 ABI 必须是 C 而不是某种语言自有的**：否则纯 libc 重写阶段被锁死，
自举终态不可达（该约束的完整依据见语言规范的「运行时 shim 边界」条款）。
**为什么用包装函数三元组**：既有两处已经在用同一个形状 ⇒ 复用而**不新造第二套**；
且「用同一个三元组再调一次」这一条使**续跑不需要第二个入口**。
**为什么帧布局不进 ABI**：各后端的帧怎么摆是它自己的事；一旦写进 ABI，
每加一个后端都要动契约 ⇒ 契约会随后端数增长，而那正是要避免的。

---

## 4. 后果

### 4.1 正面

- 语言侧的「让出」有了一个**不泄漏宿主类型**的落点，且**各后端共用同一张契约**。
- 续跑**不需要第二个入口函数**（同一个三元组再调一次）⇒ 接线面不随后端增加而分裂。
- 帧的布局**不属契约** ⇒ 新后端接入时**不动**既有 ABI。

### 4.2 代价（诚实登记，不藏）

| # | 代价 | 性质 |
|---|---|---|
| 1 | **「本次是否真让出」被压进一个返回位** | 该位是让出与占用的可观测差异所在；⛔ 它同时也是「合规降级」与「真让出」的**唯一**区别 ⇒ 判据只能读它 |
| 2 | **环境参数承担了双重角色** | 它既是实参缓冲、又是持久帧 ⇒ 派发点须按体所需尺寸分配，且**释放时机**成为契约的一部分（让出时不许释放） |

### 4.3 不承诺（明确的非目标）

- ⛔ **不承诺**帧的布局稳定（它**不属** ABI）。
- ⛔ **不承诺**本 ABI 面版本化 —— 版本化的触发条件登记在语言规范，未到即**不提前固化**
  （过早版本化是永久性 ABI 税）。

## 6. 稳定性与递交

**不递交。** 理由：本件定的是**原语层**的契约（实现与各后端之间），
不属「本规范内已定级的**语言构造**」⇒ 递交条款的对象不是它。
⚠️ 语言参考里描述**运行时与执行**的那一章可能提及这些符号的**存在**，
但那是**运行时面**的叙述，与「某条语言构造的细则移交」是两回事。
