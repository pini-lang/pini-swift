# ADR-021: 宽松词法——未知字符的兜底规则与错误后移（B6）

## Status

Accepted（2026-08-29，用户裁决；取代同日早期的「(tokens, errors) 元组」草案——该方案被否决：lexer 应永不失败，错误报告是解析/语义阶段的职责）

## Context

L0 差分门禁扩语料后，错误路径成为最后一类未对齐差异：自举 lexer 对未知字符产 `"unknown"` token，宿主抛 `E1-001` 并非零退出。Pini 语言无抛异常机制，错误只能 errors-as-data；但（tokens, errors）元组方案会让 lexer 携带渲染职责、门禁需要错误文本逐字节对拍，复杂度高。

用户裁决（2026-08-29）：**lexer 永不失败**。认不出的字符认作标识符放行，它大概率落在不合适的语法位置，由解析/语义阶段报错——错误报告的责任后移。同时给出边界约束：在有限字符范围（英文键盘全集；中文全角符号搁置）内**逐类显式覆盖**，且**标识符规则两端一致**（ADR-019 的谓词对齐即为此铺垫）。

## Decision

### D1: 未知字符兜底 = 单字符标识符

未被任何词法类（运算符最长匹配、数字、标识符、字符串、注释、空白）匹配的字符 → **单字符 IDENT token**（token 类型 = identifier，文本 = 该字符）。词法器对任何输入**永不失败**（含 EOF 防御路径）。

### D2: 字符串三边界同样宽松

1. **非法转义**（`\q` 等）：原样保留进字符串内容（反斜杠 + 字符），不报错；
2. **行尾未闭合**：字符串在换行处隐式终止（换行不消费，版面处理照常），产出已收集内容；
3. **EOF 未闭合**：同上，产出已收集内容。

`E1-002 unterminatedString` 与 `E1-001 invalidCharacter`（词法段）随之**从词法层移除**。

### D3: 畸形数字回退

进制前缀（`0x`/`0b`/`0o`，`x`/`X` 均可）后无有效数字 → 只消费 `0` 产出 `int 0`，余下走标识符通道（`0xg` → `int 0` + `identifier xg`）。浮点指数同理：`e`/`E` 后无数字 → 不消费 `e`（`1e` → `int 1` + `identifier e`）。

### D4: 标识符规则一致性

fallback 产出的 token 类型即 IDENT，与 §A.1.1 的 IDENT 判定同管道（宿主 `isLetter`/`isNumber` ≡ 自举 `is_letter`/`is_number`/`ord`，ADR-019 D3/D4 已对齐）。注意：fallback token 的**文本可含非 IDENT 字符**（如 `$`）——这正是设计意图：token 合法性交给下游裁决。

### D5: 已知限制（登记）

- **错误精度下移**：`var b = $` 的诊断从词法 E1-001「invalid character」变为解析/语义阶段的「unexpected/undefined」——位置信息保留，消息精度略降（用户裁决接受）；
- **退出码**：宿主错误退出码 1 的场景消失（lexer 不再抛错）；下游阶段的退出码对齐随 L1+ 差分处理；
- **插值体内嵌套字符串**：括号深度计数不跳过内层字符串（语料未覆盖，源内注释登记）；
- **宿主端词法诊断码 E1-001/E1-002 移除**：spec §2.6 诊断映射需随版修订。

## Consequences

**变容易**：错误路径进入 token 级对拍门禁（无需错误文本逐字节渲染）；`lex` 签名不变；两侧实现对称简单；`split("")` 同类宽松先例一致。

**变难 / 挂账**：解析器（L1）必须对「标识符出现在不合适位置」给出高质量诊断（`$` 落在表达式位 → undefined variable / unexpected token）；spec §2.6 与 §A.1.1 的修订随版落地；中文全角符号的专用处理搁置（统一走 fallback，不设计专用 token）。

## 实施记录（2026-08-29，同日落地）

- 宿主 Lexer：主扫描/operatorToken 兜底 → identifier；进制三分支预检回退；指数预检回退；字符串三边界宽松化（`LexerTests`/`LexicalTests` 三个用例随语义改写）；
- 自举 lexer.pini：opType unknown → identifier；radix 0X 对齐；字符串三边界宽松化；
- 门禁：`diff_tokens` 默认语料 **402 行 MATCH**（含全部错误路径样例）+ 中文语料 47 行 MATCH；自举测试 10/10；宿主 1024 XCTest 0 失败。
