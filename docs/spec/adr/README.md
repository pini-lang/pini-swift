# 决策记录（ADR）· 目录约定

> **本目录是决策记录的落点**，受语言规范的「语言级变更流程」与「注释规范」两节治理。
> 文件命名：`adr-<三位编号>-<slug>.md`（编号自 **001** 起，三位零填充）。

## ⚠️ 2026-09-19：编号重置

此前一批决策记录（编号 **018–043**，含一份索引表）**已整体退役**：
文件连同索引一并移除，全仓原本指向它们的 **839 处**引用**逐处改写为主题词**
（编号消失后，主题改由文字承载——例如原「见 `ADR-024 D2`」现写作「自举入树为独立嵌套仓」）。

**新编号从 `001` 开始，且与旧编号无对应关系。** 这一点必须写在这里，因为它产生一条硬约束：

> ⛔ **旧编号不得再作为指针出现。** 旧号与新号是两套互不相干的编号空间，一旦旧号被当作指引
> （「见 `ADR-024`」这类），它会被读成**指向新编号下的另一条决定**——那比「悬空」更坏：
> **悬空看得见，指错看不见**。旧号**只允许**出现在本文件描述「编号重置」这件事的说明里
> ——本文件是**唯一**许可处；其余任何载体都不得出现旧号。
> 旧决策的**结论**一律改由**主题词**承载（如原「见 `ADR-024 D2`」现写作「自举入树为独立嵌套仓」）。
>
> 门禁 `comment-lint` 的 L6 条守的是源码注释那半边（悬空即拦，见下）。

## 兑付判据（L6）

**登记表就是这些文件本身**，不再另设索引表：索引与文件是同一事实的两份副本，而副本必然漂移。

| 情形 | 判定 |
|---|---|
| 注释里有 `ADR-NNN` → 本目录有 `adr-NNN-*.md` | ✅ 可兑付 |
| 注释里有 `ADR-NNN` → 本目录无同编号文件 | ❌ **悬空，拦** |
| 注释里无 `ADR-NNN`（当前状态） | ✅ 合法——无引用即无待兑付 |

⚠️ **「扫不到引用」曾被判为失败**（旧条目的假绿防护），那条规则在编号重置后**反向**了：
零引用现在是常态。故新判据改用**阳性对照**——把合成样本喂进同一抽取式，不命中即判据失效，
以此来区分「扫不到」与「全都合规」。

## 正文卫生 —— 决策记录写「零文件级引用」

**依据**：语言规范的「注释规范」把**寿命不对称**立为通则 —— 注释是**持久、慢维护**空间；
规范段落 / 提案 / 变更记录 / 行号是**半持久、快演进**空间，注释里指向快变外部的耦合必然腐化。
**决策记录与注释同属「持久、慢维护」那一侧**，故**同规**。

**判据（唯一一条）**：该引用是否随**对方**文件编辑 / 重命名 / 章节重排 / 行移动而失效？会失效 ⇒ 不许写。

| 禁写项 | 改为 |
|---|---|
| ❌ 行号（`X.swift:123`） | 符号名 + 语义 |
| ❌ **跨文件**的章节号（`语言规范 §1.3`） | 主题词（「语言级变更流程」）或符号型 ID |
| ❌ 文档名 / 路径快照 | 主题词（「语言规范」「落地计划」） |
| ❌ 版本号叙事（`v0.42.0 转正`） | 只述**现况**（「已转正」）；演进史归变更记录 |
| ❌ 裸 `TODO` | 必带稳定 ID |

**允许写**：自包含的行为 / 不变量陈述（不跳转也懂）；**符号型稳定 ID**（`G##` / `E#-###` / `ADR-NNN` / 批号
—— 这类是**语义键**，不随文件编辑漂移）；**本文自己已声明节**的节号。

⚠️ **跨文件的章节引用必须带主题词**：
❌ 裸节号靠「本文恰好没有这一节」才能被读对 —— 本文哪天新增该节，它会**静默改指自己**，且**没有任何检查会报**。

**指针方向单向**：短命件指长寿件。提案侧写「已收口为 `ADR-NNN`」；
决策记录**反向不指**路径 —— 这样提案被归档或删除时，**本目录里零悬空**。

**门禁**：提交钩子里挂一道**文档卫生检查**，域 = **本目录的决策记录正文**：

```bash
tools/check-doc-hygiene.sh
```

以下是**显式豁免**，不是漏洞：

| 豁免 | 为什么 |
|---|---|
| **围栏代码块内的行** | 要么是可执行指令（目标没了会**报错**、看得见），要么是引例 |
| **命名模式 / 占位符**（含 `<`、`*`） | 它们描述规则本身，不指向任何实例 |
| ❌ **行内带反例记号的** | 讲规则必须举反例，否则规则说不清 |

⚠️ **域为什么只到本目录**（依据是**全仓实测**，非推断）：规范有数十处文档引用与版本号、
变更记录亦然 —— 但**那些是合法的**：规范是**权威源**（与语言参考互引是它的职责，
且其登记表里的版本号是**权威数据**，删了就是毁证据）；变更记录的版本叙事**就是它的内容**；
提案 / 落地计划是**工作件**，指向过程材料是本职。
⇒ **本条只管「结论件」** —— 按**寿命方向**定域，不按「是不是文档」定域。

## 与旧编号体系的关系

| 事项 | 说明 |
|---|---|
| 旧记录的**内容** | 不再随仓分发；如需追溯，见版本历史（`git log --diff-filter=D -- docs/spec/adr/`） |
| 旧记录的**结论** | 已化作各自载体上的**主题词陈述**——约束仍在，只是不再挂编号 |
| 新记录怎么写 | 按注释风格指南与语言规范的「注释规范」；**只增不改**，编号不复用 |
