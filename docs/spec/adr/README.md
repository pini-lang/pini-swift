# 决策记录（ADR）· 目录约定

> **本目录是决策记录的落点**，受 `../pini-spec-v0.md` §1.3 与 §7 治理。
> 文件命名：`adr-<三位编号>-<slug>.md`（编号自 **001** 起，三位零填充）。

## ⚠️ 2026-09-19：编号重置

此前一批决策记录（编号 **018–043**，含一份 `adr-index.md` 索引表）**已整体退役**：
文件连同索引一并移除，全仓原本指向它们的 **839 处**引用**逐处改写为主题词**
（编号消失后，主题改由文字承载——例如原「见 `ADR-024 D2`」现写作「自举入树为独立嵌套仓」）。

**新编号从 `001` 开始，且与旧编号无对应关系。** 这一点必须写在这里，因为它产生一条硬约束：

> ⛔ **旧编号不得再作为指针出现。** 旧号与新号是两套互不相干的编号空间，一旦旧号被当作指引
> （「见 `ADR-024`」这类），它会被读成**指向新编号下的另一条决定**——那比「悬空」更坏：
> **悬空看得见，指错看不见**。旧号**只允许**出现在本文件描述「编号重置」这件事的说明里
> ——本文件是**唯一**许可处；其余任何载体都不得出现旧号。
> 旧决策的**结论**一律改由**主题词**承载（如原「见 `ADR-024 D2`」现写作「自举入树为独立嵌套仓」）。
>
> 门禁 `hooks/comment-lint.sh` 的 L6 条守的是源码注释那半边（悬空即拦，见下）。

## 兑付判据（L6）

**登记表就是这些文件本身**，不再另设索引表：索引与文件是同一事实的两份副本，而副本必然漂移。

| 情形 | 判定 |
|---|---|
| 注释里有 `ADR-NNN` → 本目录有 `adr-NNN-*.md` | ✅ 可兑付 |
| 注释里有 `ADR-NNN` → 本目录无同编号文件 | ❌ **悬空，拦** |
| 注释里无 `ADR-NNN`（当前状态） | ✅ 合法——无引用即无待兑付 |

⚠️ **「扫不到引用」曾被判为失败**（旧条目的假绿防护），那条规则在编号重置后**反向**了：
零引用现在是常态。故新判据改用**阳性对照**——把合成样本喂进同一抽取式，不命中即判据失效，
以此来区分「扫不到」与「全都合规」。

## 与旧编号体系的关系

| 事项 | 说明 |
|---|---|
| 旧记录的**内容** | 不再随仓分发；如需追溯，见版本历史（`git log --diff-filter=D -- docs/spec/adr/`） |
| 旧记录的**结论** | 已化作各自载体上的**主题词陈述**——约束仍在，只是不再挂编号 |
| 新记录怎么写 | 按 `../pini-comment-style-guide.md` 与 §7；**只增不改**，编号不复用 |
