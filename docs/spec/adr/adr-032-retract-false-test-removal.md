# ADR-032：撤回「假测试清除」，并规定门控测试的环境判据

- 状态：Accepted（2026-09-07）
- 关联：ADR-031（`docs/spec/adr/adr-031-llvm-backend-rewrite.md`）
- 影响面：`Tests/PiniTests`（测试资产的删除判据）

> 本 ADR 撤回 ADR-031 的 §4 步骤 1、§6 落地记录，以及 §2 中的 N-2 与 N-3 两条论证。
> ADR-031 的其余部分（重写方向、约束 1～5、止损判据）继续有效。

---

## 1. 约束（本 ADR 改变了什么）

1. **门控测试的环境判据必须先于结论**：凡以「某个外部命令是否可用」为前提的
   测试结论（跳过率、失败数、通过基线），必须在**完整登录 shell 环境**下实测。
   判据：执行 `source ~/.zshrc` 后 `command -v <tool>` 有输出，才算该工具存在。
2. **「恒跳过」不构成删除理由**：删除一个测试前，须证明它在完整环境下仍然跳过；
   仅凭一次残缺环境的测量不得删除任何测试文件或夹具。
3. **门控缺失须显式失败**（沿用 ADR-031 约束 5）：禁止 `XCTSkip` 静默跳过。
4. **锁死实现细节的断言不得先行删除**：断言 IR 文本形态的测试是重写期的枷锁，
   但在旧实现退役前它也是唯一的回归信号；只允许在与「旧实现删除」同批提交中移除。
5. **工作树/沙箱路径下的测量不作为判据**：`locateRuntimeDylib()` 依赖仓内
   `.build/debug`，自定义 `--scratch-path` 与 `git worktree` 都会使其失效。

---

## 2. 必要性（不撤回会怎样）

ADR-031 §2 的实测表由两层环境假象共同伪造，均已在完整环境下复测推翻：

| 对象 | 残缺环境测得（ADR-031 记载） | 完整环境实测（2026-09-07） |
|---|---|---|
| 全量 | 1214 / 114 skip | 1215 / **0 skip** / **0 failure** |
| `IRExecutionTests` | 73/82 skip | **82/82 通过** |
| `IRPrintGoldenTests` | 2/2 skip（工作树下 8 处失败） | **2/2 通过** |
| `RuntimeBackendTests` | 37/51 skip（工作树下 38/51） | **51/51 通过** |
| `OptionalTests` | 2/20 skip | **20/20 通过** |

- **N-1 假象一：PATH 残缺**。测量环境的 PATH 不含 `/opt/homebrew/bin`，
  `lli` 因此"不存在"。该命令在完整环境下存在（LLVM 22.1.8）。
- **N-2 假象二：dylib 路径失效**。运行时 dylib 由仓内 `.build/debug` 定位；
  在 `git worktree` 复测时该目录不存在，额外产生 38 个跳过与 8 处 golden 失败。
- **N-3 结论**：ADR-031 的 N-2「测试资产结构倒挂」与 N-3「门后腐烂已实证」
  两条论证不成立——被删的 225 个测试在完整环境下 **全部实跑且全部通过**。
  据此执行的删除（commit `49aae31`）已回退。

---

## 3. 充分性（如何保证不再复发）

- **S-1 可机械核验**：约束 1 的判据是 `command -v` 是否有输出，无主观成分。
- **S-2 门槛对称**：约束 2 要求"证明仍跳过"而非"看起来跳过"，
  举证责任在删除方。
- **S-3 与既有缺陷不冲突**：`docs/issue-gated-stale-fixtures-2026-09-05.md`
  记录的是"长期 skip 导致夹具腐烂"的真实风险，本 ADR 不否认该风险；
  约束 3 以「显式失败」取代「静默 skip」，是同一风险的正确处置。
