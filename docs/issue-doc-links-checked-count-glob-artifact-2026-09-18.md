# Issue：`check-doc-links.sh` 的 `checked` 读数含 glob 伪影（判据本身不受影响）

> **日期**：2026-09-18｜**状态**：**Open**（只登记不修）
> **发现于**：工单巡查批（round 1）—— 归档 6 张工单后按惯例跑链接校验，
> 读到 `987`，而 memory 日志里 `G-5` 批记的是 `1008`。按「断言失败先怀疑断言」追查，定位到本缺陷。
> **性质**：**读数缺陷，不是判据缺陷** —— 门禁的 PASS/FAIL 判定仍然有效（论证见 §3）。
> **归属**：器械类，**不阻塞**任何批次（`charter.md` D2：不满足「构成阻塞」⇒ 登记不修）。

## 0. 一句话

`tools/check-doc-links.sh` 用 `for ref in $refs`（**变量未加引号**）遍历抽取到的引用 token。
文档里存在含 `*` 的 token（如 `` `docs/issue-*.md` ``）⇒ bash 对它做**路径名展开**，
一个 token 被展开成**当前实际匹配的文件列表** ⇒ `checked` 计数被虚增，
且**随工作树的文件增减而漂**。

## 1. 符号级根因

```bash
# tools/check-doc-links.sh（现行）
refs="$(grep -oE '\`[^ \`[:space:]]+\.(md|toml)\`' "$f" 2>/dev/null | tr -d '\`' | sort -u)"
for ref in $refs; do          # ← $refs 未加引号
```

未加引号的变量展开会依次做：分词 → **路径名展开（glob）** → 去引号。
含 `*` / `?` / `[` 的 token 在第二步被展开成匹配的实际文件路径。
展开出的词都是**真实存在的路径**，所以 `[ -e ]` 判定照样通过 ⇒ **不产生假 FAIL**，
但 `checked=$((checked + 1))` 被多算。

## 2. 实测（2026-09-18，可复现）

判据装置：逐文件复现校验器的累加逻辑，**两次运行只差 `set -f`（禁用 glob）**。

| 状态 | 带 glob 伪影 | **禁用 glob（干净）** | 差 |
|---|:--:|:--:|:--:|
| 改前（`63f6a04`） | `1003` | **`746`** | 257 |
| 改后（本轮工作树） | `987` | **`753`** | 234 |

**两条结论**：

1. **干净口径下改前后为 `746 → 753`（**+7**）** —— 与独立口径（Python `re.findall`，逐文件对比
   `751 → 758`）的**增量完全一致（+7）** ⇒ 该批**没有丢引用**。
2. ⚠️ **带伪影的口径下是 `1003 → 987`（**−16**）** —— 方向相反。
   根因：`docs/issue-*.md` 这类 token 的展开结果**随 `docs/` 下文件增减而变**，
   本轮把 6 张工单移入 `archive/` ⇒ 展开少 6 个词，与内容改动叠加成 −16。

⇒ **`checked` 数不可跨状态比较**。memory 日志里 `G-5` 记的 `1008`、
本轮改前的 `1003`、改后的 `987`，**三者互不可比**，也不应作为「链接面规模」的读数使用。

### 2.1 ⭐ 本单自身造成的第三个实例（同一现象，可现场复现）

本单**落盘之后**再跑校验器，`checked` 由 `987` 跳为 **`1047`（**+60**）**。
唯一相关的改动是：本单 §0 写了 `` `docs/issue-*.md` `` 这一个**通配 token**
⇒ bash 把它展开成 `docs/` 下实际匹配的 ~60 个文件 ⇒ 读数一次跳 60。

⇒ 这是本缺陷最干净的演示：**读数的变化与「引用面」无关，只与「文件集」有关**。
⚠️ 也提醒：**不要把 `checked` 当作「文档引用规模」引用**（它同时受文件数量与 token 内容影响）。

## 3. 为什么这是读数缺陷而非判据缺陷

判据是「抽取到的引用，按文档所在目录 / 仓根解析，都不存在且 basename 在本仓存在 ⇒ 报过时」。

- glob 展开引入的词是**匹配到的真实文件路径**，它们都 `-e` 通过 ⇒ 不产生假 FAIL；
- 展开**不会**让原本该报的过时引用逃逸（原 token 本身仍在词表里，仍被逐条检查）。

⇒ **门禁结论有效**。本单只针对那个被打印出来的计数。

## 4. 处置候选（不预设，本单不修）

| 选项 | 动作 | 代价 |
|---|---|---|
| **A** | `for ref in $refs` → `while IFS= read -r ref`（含 `printf '%s\n' "$refs"` 管道） | 一行 + 一处管道；**不动 `cand` 的 `ls ./*.md`**（那处 glob 是有意的） |
| **B** | 脚本顶部加 `set -f` | 更短，但会**顺带废掉 `ls ./*.md` 的 glob** ⇒ `cand` 少掉仓根 md（实测 files 从 161 掉到 159）⇒ 需同时把 `ls` 换成 `find . -maxdepth 1 -name '*.md'` |
| **C** | 登记不修，只在使用侧记「该数不可比」 | 零成本；缺一个能反映真实规模的读数 |

⚠️ **A 与 B 都只改读数、不改判据** ⇒ 任一都不会让门禁变松或变紧。

## 5. 复现方式

```sh
# 判据装置：两次运行只差 set -f
cat > /tmp/repro-refcount.sh <<'SH'
#!/usr/bin/env bash
set -u
cd "$1" || exit 1
cand="$( { find docs -name '*.md' -not -path '*/.build/*' 2>/dev/null; ls ./*.md 2>/dev/null; } | sort -u )"
checked=0
for f in $cand; do
  [ -f "$f" ] || continue
  refs="$(grep -oE '\`[^ \`[:space:]]+\.(md|toml)\`' "$f" 2>/dev/null | tr -d '\`' | sort -u)"
  for ref in $refs; do
    [ -n "$ref" ] || continue
    case "$ref" in pini.toml|*"<"*) continue ;; esac
    checked=$((checked + 1))
  done
done
echo "checked=$checked"
SH
bash /tmp/repro-refcount.sh .            # 带伪影
sed -i '' 's/^set -u$/set -u\nset -f/' /tmp/repro-refcount.sh
bash /tmp/repro-refcount.sh .            # 干净

# 通配 token 的存在性（文档里确实有）
grep -rhoE '`[^ `[:space:]]+\*[^ `[:space:]]*\.(md|toml)`' docs/ | sort -u
```

⚠️ **一处方法教训**（本单的追查过程）：**凡含反引号的正则，不要在 Bash 工具的命令行里复现** ——
多层转义会把正则吃变形（本单实测：同一正则在命令行里得 `0`，写进脚本文件得正确值）。
⇒ 定式：**写脚本文件跑**，或直接用绝对路径工具 + 参数数组（不经 shell 解析）。
