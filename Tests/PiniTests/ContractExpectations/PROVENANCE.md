# 契约期望（layer 3 的判据输入）

> 本目录是**期望根**（`tools/hir-spec-assert.py` 的 `EXPECT_ROOT`）。
> **语料不在这里** —— 它们在 `examples/`（同件的 `FIXTURE_ROOT`）。
> 语料**只有一份**是刻意的：第二个副本就是第二个会漂的东西，本仓已为此付过一次代价。

## 本目录的规则

1. **在册即被守卫。** 受检集 = 本目录下**每一个 `.expected`**，**不是** `examples/` 下每一个 `.pini`。
   新增示例**不会**自动进守卫；新增期望件**会**。
   （反过来读会让整棵示例树一夜之间变成红账 —— 所以这条是判据，不是风格。）

2. ⭐ **期望值必须手写**（或按规范推导），**不得**由任一通道的输出回抄。
   回抄会让 layer 3 静默退化成 layer 1 —— 那时它只会报「实现与自己一致」。
   器械为此设了两道闸：`--generate` 要求 `--force`，只在不一致时拒绝生成，并给产物打 `GENERATED` 戳。

3. **断言面 = 标准输出逐字节 + 退出码。标准错误不判** ——
   已知若干诊断通道不对称（记在调度面提案 §2.8），把它们拉进来会让新器械淹没在既有缺陷里。

4. **参照物是契约，不是另一条腿。** 每个通道**各自**与本目录这一份期望比；
   不是「解释器 vs LLVM」两两对比 —— 后端变多时，前者线性、后者二次。

## 为什么今天只有一条

`examples/` 下有 8 份 `concurrency*` 语料，但**只有 1 份可达**：其余 7 份**两条通道
停在同一个上游门禁**（`print(e)` 那处 `E6-004`，见提案 §8.7 与 §11 的 `DE-4` 规划落档）。
所以本目录今天的覆盖面 = **1 个断言点**，而它守的是「形态已经通了」，**不是**覆盖面。
⛔ 不要把本目录的存在读成「并发面已被守卫覆盖」。
